Модуль `@exode-team/sdk/miniapp/react` предоставляет декларативный слой над `ExodeMiniApp` для React-приложений. Все хуки реактивные: при событиях хоста компоненты автоматически перерендериваются.

<Info>
  React — опциональная peer-зависимость. Если в проекте нет React, этот модуль не нужен — используйте [ванильный клиент](/ru/exode-sdk/miniapp/client).
</Info>

## Provider

Оборачивает приложение, создаёт `ExodeMiniApp`, выполняет handshake и распространяет подписки на события:

```jsx
import { ExodeMiniAppProvider } from '@exode-team/sdk/miniapp/react'

function App() {
  return (
    <ExodeMiniAppProvider config={{ appId: 'my-app', targetOrigin: 'https://my-school.exode.biz' }}>
      <MyApp />
    </ExodeMiniAppProvider>
  )
}
```

### Параметры

<ResponseField name="config" type="ExodeMiniAppProviderConfig" required>
  Конфигурация клиента: `appId`, `targetOrigin?`, `timeout?`, `edgeToEdge?`, `applyEnvironment?`, `applyTheme?`
  (см. [параметры `ExodeMiniApp`](/ru/exode-sdk/miniapp/client#параметры-конфигурации)) плюс `renderMode?`.
  В отличие от `ExodeMiniApp`, у провайдера `edgeToEdge` и `applyTheme` по умолчанию включены (SDK 0.4+): в
  приложении фрейм уходит под шапку и нижнее меню хоста, `<body>` получает отступы по `--exode-inset-*`, фон и цвет
  текста — из цветов школы. Чтобы вести отступы или тему самому, передайте `edgeToEdge: 'manual'` или
  `applyTheme: false` — см. [Нативный вид](/ru/exode-sdk/miniapp/native#края-и-тема).

  <Expandable title="renderMode">
    Режим рендеринга детей:
    - `'defer'` (по умолчанию) — дети монтируются только после завершения handshake (успешного или с ошибкой);
      до этого провайдер рендерит `null`.
    - `'immediate'` — дети монтируются с первого рендера (в т.ч. при SSR); до готовности хуки возвращают
      значения по умолчанию (`scheme: 'light'`, `user: null` и т.п.).
  </Expandable>
</ResponseField>

## useExodeApp

Состояние подключения и низкоуровневый доступ к инстансу `ExodeMiniApp`.

```jsx
function Status() {
  const { app, isReady, error } = useExodeApp()

  if (error) return <div>Ошибка подключения: {error.message}</div>
  if (!isReady) return <div>Соединение с Exode...</div>

  return <div>Подключено</div>
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `app` | `ExodeMiniApp` | Экземпляр клиента (создаётся при первом рендере провайдера, до handshake) |
| `isReady` | `boolean` | Handshake завершён |
| `error` | `Error \| null` | Ошибка инициализации (например, приложение открыто не в iframe или хост не ответил за `timeout`) |

<Note>
  В режиме `renderMode: 'defer'` (по умолчанию) дети провайдера не монтируются, пока идёт handshake, поэтому
  ветка «Соединение с Exode...» из примера выше не отрисуется. Чтобы показывать состояние загрузки, используйте
  `renderMode: 'immediate'`.
</Note>

## useExodeUser

Текущий пользователь. Обновляется на событии `user:updated`. `isLoggedIn` — `true`, если `user.id > 0`;
для неавторизованного посетителя страницы хост передаёт `user.id === 0`.

```jsx
function Greeting() {
  const { user, isLoggedIn } = useExodeUser()

  if (!isLoggedIn) return <div>Не авторизован</div>

  return <div>Привет, {user?.firstName}</div>
}
```

## useExodeTheme

Текущая тема. Обновляется на событии `theme:changed`. Также возвращает `isReady` — получена ли тема от хоста, и
с хостом 0.4+ — `accent` (акцент школы, CSS-цвет) и `colors` (цвета хоста, `MiniAppThemeColors`); со старым хостом
они `null`. До handshake схема берётся из имени фрейма, которое хост задаёт при открытии.

```jsx
function ThemedBox() {
  const { scheme, isDark } = useExodeTheme()

  return (
    <div style={{ background: isDark ? '#1a1a1a' : '#ffffff' }}>
      Схема: {scheme}
    </div>
  )
}
```

## useExodeSchool

Данные школы. Обновляется на событии `school:updated`.

```jsx
function SchoolInfo() {
  const { school } = useExodeSchool()

  return <div>{String(school?.name ?? '')}</div>
}
```

## useExodeConfig

Конфигурация окружения. Обновляется на событии `config:updated`. Поле `os` (`ios` / `android` / `web`) передаёт
хост 0.4+, со старым хостом — `null`.

```jsx
function Layout({ children }) {
  const { isDesktop, isMobile, language, platform } = useExodeConfig()

  return (
    <div className={isMobile ? 'layout-compact' : 'layout-wide'} lang={language}>
      {children}
    </div>
  )
}
```

## useExodeNavigation

Команды навигации основного приложения. `navigate(path, params)` принимает шаблон маршрута и параметры —
см. раздел «Навигация» в [Клиент ExodeMiniApp](/ru/exode-sdk/miniapp/client).

```jsx
function NavButtons() {
  const { navigate, back } = useExodeNavigation()

  return (
    <>
      <button onClick={() => navigate('/course/:courseId([0-9_A-Za-z]+)', { courseId: '123' })}>
        Открыть курс
      </button>
      <button onClick={() => back()}>Назад</button>
    </>
  )
}
```

## useExodeUI

UI-команды к хосту. С SDK 0.4 хук возвращает и `openLink(url, { external? })`, `share({ url?, text?, title? })` и
`copyText(text)` — см. [Нативный вид](/ru/exode-sdk/miniapp/native).

```jsx
function Controls() {
  const { showSnackbar, setTabbarVisible, setHeaderVisible, minimize, close } = useExodeUI()

  return (
    <>
      <button onClick={() => showSnackbar({ message: 'Готово!', type: 'success' })}>
        Уведомление
      </button>
      <button onClick={() => setTabbarVisible(false)}>Скрыть tabbar</button>
      <button onClick={() => minimize()}>Свернуть окно</button>
      <button onClick={() => close()}>Закрыть приложение</button>
    </>
  )
}
```

<Note>
  `minimize` работает только для страниц с типом окна «Плавающее окно», «Панель справа» или «Во весь экран»
  (см. [Кастомные страницы](/ru/customization/custom-pages)). Отследить сворачивание можно
  хуком `useExodeVisibility`. `setHeaderVisible` на кастомных страницах пока ничего не меняет.
</Note>

## useExodeVisibility

Видно ли приложение пользователю прямо сейчас. Хост не выгружает iframe при уходе на другую
страницу и при сворачивании окна — вместо этого он присылает `visibility:changed`. Используйте
хук, чтобы останавливать опросы, видео и анимации в фоне.

```jsx
import { useEffect } from 'react'

function Poller() {
  const { visible } = useExodeVisibility()

  useEffect(() => {
    if (!visible) return

    const timer = setInterval(() => refetch(), 5000)

    return () => clearInterval(timer)
  }, [ visible ])

  return <Dashboard/>
}
```

## useExodeInitData

Подписанная строка [Init Data](/ru/exode-sdk/miniapp/init-data) из адреса iframe (`#exodeInitData=...`).
Значение читается один раз, удаляется из адресной строки и кэшируется. Провайдер для этого хука не нужен.
Отправьте строку на свой бэкенд и проверьте её там функцией `verifyInitData` — в браузере ей доверять нельзя.

```jsx
import { useEffect } from 'react'
import { useExodeInitData } from '@exode-team/sdk/miniapp/react'

function Session() {
  const { initData } = useExodeInitData() // string | null — null when opened outside Exode

  useEffect(() => {
    if (!initData) return

    fetch('/api/session', { method: 'POST', headers: { 'X-Exode-Init-Data': initData } })
  }, [ initData ])

  return null
}
```

## Хуки нативного вида (SDK 0.4+)

Хуки хрома хоста подробно описаны на странице [Нативный вид](/ru/exode-sdk/miniapp/native).

| Хук | Что даёт |
|-----|----------|
| `useExodeSupports()` | Функция `(capability) => boolean`: умеет ли хост это (до handshake и со старым хостом — `false`) |
| `useExodeViewport()` | `viewport`, `insets`, `isFullscreen`, `isEdgeToEdge`, `orientation`, `requestFullscreen`, `exitFullscreen`, `lockOrientation`, `unlockOrientation` |
| `useExodeHeader({ title, left, right, onButton })` | Заголовок и пункты меню «…» шапки, пока компонент смонтирован |
| `useExodeBackButton(handler \| null)` | «Назад» ведёт по экранам приложения, пока передан обработчик |
| `useExodeMainButton({ text, loading, disabled, color, textColor, visible, onClick })` | Главная кнопка у низа экрана |
| `useExodeComposer({ ...params, onSubmit, onVoice, onChange, onStop, onScrollDown })` | Поле ввода с микрофоном, в том числе «только голос» |
| `useExodePopup()` | `show`, `alert`, `confirm`, `prompt` |
| `useExodeHaptic()` | `impact`, `notification`, `selection` |

`useExodeHeader`, `useExodeBackButton`, `useExodeMainButton` и `useExodeComposer` возвращают `isSupported` — если
`false`, отрисуйте свой интерфейс. Шапка, главная кнопка и поле ввода у хоста одни: один такой хук на экран.

## Требования

<Warning>
  Все хуки, кроме `useExodeInitData`, работают только внутри `<ExodeMiniAppProvider>`. Вызов за его пределами
  выбросит ошибку.
</Warning>

## Полный пример

```jsx
import {
  ExodeMiniAppProvider,
  useExodeApp,
  useExodeUser,
  useExodeTheme,
  useExodeUI,
} from '@exode-team/sdk/miniapp/react'

function Content() {
  const { isReady, error } = useExodeApp()
  const { user } = useExodeUser()
  const { isDark } = useExodeTheme()
  const { showSnackbar } = useExodeUI()

  if (error) return <div>Ошибка: {error.message}</div>
  if (!isReady) return <div>Загрузка...</div>

  return (
    <div data-theme={isDark ? 'dark' : 'light'}>
      <h1>Привет, {user?.firstName ?? 'гость'}</h1>
      <button onClick={() => showSnackbar({ message: 'Привет!', type: 'info' })}>
        Показать уведомление
      </button>
    </div>
  )
}

export default function App() {
  return (
    <ExodeMiniAppProvider config={{ appId: 'my-app', renderMode: 'immediate' }}>
      <Content />
    </ExodeMiniAppProvider>
  )
}
```
