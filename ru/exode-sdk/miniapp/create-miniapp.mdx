Мы подготовили **готовый skill для AI-агента** (Claude Code, Cursor, ChatGPT и т.п.):
агент сам устанавливает инструменты, создаёт приложение, проверяет подпись
`exodeInitData` на сервере, деплоит на Vercel или Cloudflare и подключает
приложение к вашей школе.

<Tip>
  **Уметь программировать не требуется** — все технические шаги агент выполняет сам.
</Tip>

## Как воспользоваться

Дайте агенту ссылку на skill и попросите следовать ему:

```
https://docs.exode.biz/skills/create-miniapp.md
```

Например, напишите агенту: «Скачай https://docs.exode.biz/skills/create-miniapp.md
и сделай всё по этой инструкции. Я хочу приложение, которое …».

От вас потребуется только три вещи:

1. Аккаунт на хостинге (агент подскажет, где зарегистрироваться — Vercel или Cloudflare).
2. Секрет страницы из админки школы (**Компания → Приложения и страницы → ⋯ → Показать секрет**).
3. Вставить итоговую https-ссылку приложения в админку.

<Info>
  Skill написан на английском — так агенты работают точнее всего. Общаться с агентом
  можно на русском: в инструкции ему прямо сказано отвечать на языке пользователя.
</Info>

Тот же skill доступен агентам автоматически через Agent Skills Discovery:
`https://exode.biz/.well-known/agent-skills/exode-create-miniapp/SKILL.md`.
