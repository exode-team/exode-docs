`ExodeMiniApp` — основной класс клиента. Один экземпляр на приложение. Все методы типизированы и возвращают `Promise`.

## Создание экземпляра

```ts
import { ExodeMiniApp } from '@exode-team/sdk/miniapp'

const app = new ExodeMiniApp({
  appId: 'my-app',                             // required
  targetOrigin: 'https://my-school.exode.biz', // origin of the school; default '*'
  timeout: 10_000,                             // ms, default 10000
})
```

### Параметры конфигурации

<ResponseField name="appId" type="string" required>
  Идентификатор мини-приложения, передаётся хосту при handshake. Для [кастомных страниц](/ru/customization/custom-pages)
  значение выбирается произвольно и нигде не регистрируется: хост доверяет приложению по origin адреса из поля
  «URL приложения (iframe)».
</ResponseField>

<ResponseField name="targetOrigin" type="string">
  Origin страницы школы, внутри которой открыто приложение, — например `https://my-school.exode.biz` или ваш
  собственный домен школы. SDK отправляет сообщения только на этот origin и принимает ответы только от него.
  По умолчанию `*` (любой origin) — в этом случае SDK пишет предупреждение в консоль. В продакшене указывайте
  origin явно.
</ResponseField>

<ResponseField name="timeout" type="number">
  Таймаут handshake и всех команд (мс). По умолчанию `10000`.
</ResponseField>

<Warning>
  Клиент должен исполняться **внутри iframe**. Попытка `init()` в top-level окне выбросит ошибку `ExodeMiniApp must be used inside an iframe`.
</Warning>

## Инициализация

```ts
const ctx = await app.init()

console.log(ctx.user.firstName)
console.log(ctx.theme.scheme)
```

Метод выполняет handshake с хостом и возвращает [`MiniAppContext`](/ru/exode-sdk/miniapp/context). Повторный вызов `init()` выбросит ошибку.

Если страница открыта без входа (опция «Доступна без входа»), handshake всё равно проходит, но `ctx.user.id`
равен `0`, а персональные поля пустые — проверяйте `ctx.user.id > 0`, прежде чем показывать данные пользователя.

<Warning>
  Контекст из `init()` не подписан и подходит только для отображения. Чтобы достоверно узнать пользователя на
  своём бэкенде, используйте [Init Data](/ru/exode-sdk/miniapp/init-data).
</Warning>

<Info>
  Если handshake не успел завершиться за `timeout` мс — Promise отклоняется. Проверьте, что iframe открыт внутри Exode и `targetOrigin` корректен.
</Info>

## Навигация (app.route)

`path` — это шаблон маршрута платформы (а не готовый URL), значения подставляются из `params`:

```ts
// Open the course page: route template + params
await app.route.navigate('/course/:courseId([0-9_A-Za-z]+)', { courseId: '123' })

// Back through host history
await app.route.back()
```

Шаблоны маршрутов те же, что и в [deep link-ах мобильного приложения](/ru/customization/mobile-app#другие-экраны)
(`pageId`). Текущий маршрут хоста в том же формате приходит в событии `route:changed`.

<Note>
  Когда приложение скрыто (пользователь ушёл на другую страницу или свернул окно), хост игнорирует команды
  `navigate`, `navigate:back` и `setTabbarVisible`.
</Note>

## UI-команды (app.ui)

```ts
// Snackbar notification
await app.ui.showSnackbar({
  message: 'Сохранено!',
  type: 'success', // 'success' | 'error' | 'info'
})

// Hide / show host bottom navigation
await app.ui.setTabbarVisible(false)

// Hide / show host header (see the note below)
await app.ui.setHeaderVisible(false)

// Minimize the window (window-type pages only)
await app.ui.minimize()

// Close the mini app
await app.ui.close()
```

<Note>
  `minimize()` работает только для страниц с типом окна «Плавающее окно», «Панель справа» или «Во весь экран»
  (см. [Кастомные страницы](/ru/customization/custom-pages)). Свёрнутое окно не выгружается —
  приложение получает событие `visibility:changed` с `visible: false` и продолжает жить.

  На кастомных страницах школы команда `setHeaderVisible` сейчас не обрабатывается хостом и ничего не меняет.
</Note>

<Info>
  Promise команды разрешается, когда хост подтвердил получение. Хост подтверждает и те команды, которые
  в текущем контексте ничего не делают, поэтому успешное выполнение Promise не гарантирует видимого эффекта.
</Info>

## События (app.on)

Подписка на события хоста. Возвращает функцию отписки.

```ts
const unsubscribe = app.on('theme:changed', (theme) => {
  document.body.className = theme.scheme
})

app.on('user:updated', (user) => {
  console.log('User changed:', user.firstName)
})

app.on('route:changed', ({ path, params }) => {
  console.log('Host navigated to:', path)
})

// Unsubscribe
unsubscribe()
```

<Tip>
  Полный список событий и их payload'ов — в разделе [Контекст и типы](/ru/exode-sdk/miniapp/context).
</Tip>

## Получение текущего контекста

`init()` возвращает контекст один раз. Для последующего доступа используйте `getContext()`: он возвращает
контекст из handshake, к которому bridge применяет только события `context:updated`.

<Warning>
  События `theme:changed`, `user:updated`, `school:updated` и `config:updated` **не** обновляют объект из
  `getContext()`. Если вам нужны актуальные тема, пользователь или конфиг, подпишитесь на эти события через
  `app.on(...)` и храните значения у себя — или используйте [React-хуки](/ru/exode-sdk/miniapp/react), которые
  делают это автоматически.
</Warning>

```ts
const ctx = app.getContext()

if (ctx) {
  console.log(ctx.user.firstName)
}
```

## Завершение работы

```ts
app.destroy()
```

Закрывает bridge, отключает слушатели `postMessage`, очищает обработчики событий. Вызывайте при размонтировании приложения.

## Полный пример

```ts
import { ExodeMiniApp } from '@exode-team/sdk/miniapp'

const app = new ExodeMiniApp({
  appId: 'my-app',
  targetOrigin: 'https://my-school.exode.biz',
})

async function start() {
  const ctx = await app.init()

  document.body.className = ctx.theme.scheme
  document.getElementById('hello')!.textContent = ctx.user.id > 0
    ? `Привет, ${ctx.user.firstName ?? ''}`
    : 'Привет, гость'

  app.on('theme:changed', (theme) => {
    document.body.className = theme.scheme
  })

  document.getElementById('btn-save')!.addEventListener('click', async () => {
    await app.ui.showSnackbar({ message: 'Сохранено!', type: 'success' })
  })
}

start().catch(console.error)

window.addEventListener('beforeunload', () => app.destroy())
```
