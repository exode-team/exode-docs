## Установка через npm

<CodeGroup>
```bash npm
npm install @exode-team/sdk
```

```bash yarn
yarn add @exode-team/sdk
```

```bash pnpm
pnpm add @exode-team/sdk
```
</CodeGroup>

<Tip>
  React — опциональная peer-зависимость. Если проект не использует React, модуль `miniapp/react` не подтянет его и не попадёт в бандл.
</Tip>

## Импорты

У пакета четыре subpath-экспорта — импортируйте только нужный:

```ts
import { ExodeAPI }        from '@exode-team/sdk/api'             // сервер (Node.js)
import { ExodeMiniApp }    from '@exode-team/sdk/miniapp'         // браузер, внутри iframe
import { useExodeUser }    from '@exode-team/sdk/miniapp/react'   // браузер + React
import { verifyInitData }  from '@exode-team/sdk/miniapp/server'  // сервер (Node.js)
```

<Warning>
  `@exode-team/sdk/api` и `@exode-team/sdk/miniapp/server` предназначены только для сервера: первый работает
  с API-токеном школы, второй — с секретом страницы и использует модуль `crypto` из Node.js. Не импортируйте их
  в клиентский бандл.
</Warning>

<Warning>
  Не импортируйте из корня (`@exode-team/sdk`) — корневой экспорт не определён, чтобы избежать случайной загрузки серверного и клиентского кода в одном бандле.
</Warning>

## Подключение через CDN

Для статических страниц без сборки доступен IIFE-бандл MiniApp-модуля (`ExodeMiniApp`, `retrieveInitData`).
React-хуки и серверные функции через CDN не поставляются.


<CodeGroup>

```html Конкретная версия (рекомендуется)

<script src="https://static.exode.biz/sdk/v0.3.1/miniapp.global.js"></script>

```


```html Последняя версия

<script src="https://static.exode.biz/sdk/latest/miniapp.global.js"></script>

```

</CodeGroup>

После подключения глобальный объект `ExodeMiniAppSDK` становится доступен:

```html
<script>
  const app = new ExodeMiniAppSDK.ExodeMiniApp({ appId: 'my-app' })

  app.init().then((ctx) => {
    console.log('User:', ctx.user.firstName)
  })

  // Подписанные данные пользователя для вашего бэкенда (см. раздел Init Data)
  const initData = ExodeMiniAppSDK.retrieveInitData()
</script>
```

<Info>
  В продакшене всегда фиксируйте версию (`v0.3.0`, `v0.3.1` и т. д.). Тег `latest` обновляется автоматически и может внести ломающие изменения.
  `retrieveInitData` есть в CDN-бандле начиная с `v0.3.1`. Номера версий на CDN могут отставать от npm — если нужной
  версии нет на CDN, используйте установку через npm.
</Info>

## TypeScript

Типы поставляются вместе с пакетом, дополнительный `@types/...` не требуется.

```ts
import type { ExodeAPIConfig, User } from '@exode-team/sdk/api'

import type {
  ExodeMiniAppConfig,
  MiniAppContext,
  MiniAppUser,
} from '@exode-team/sdk/miniapp'

import type { InitDataPayload } from '@exode-team/sdk/miniapp/server'

// Тип Platform отдельно не экспортируется — берите его из контекста:
type Platform = MiniAppContext['platform'] // 'web' | 'native'
```
