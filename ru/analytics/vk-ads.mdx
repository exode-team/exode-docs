## Подключение

Вставьте стандартный сниппет пикселя VK Ads в **Custom Code (JS)** в настройках школы
и дополнительно укажите его ID в `window.VK_PIXEL_ID`:

```html
<script>
    // ... стандартный сниппет пикселя VK Ads ...

    window.VK_PIXEL_ID = 3456789; // ID вашего пикселя
</script>
```
