Сайт школы по умолчанию открыт для поисковых систем: платформа сама отдаёт `robots.txt` и `sitemap.xml`, а мета-теги
страницы (заголовок, описание, canonical) сервер кладёт в `<head>` исходного HTML — раньше кода из
[«Кастомного HTML»](/ru/customization/js-config). Атрибут `lang` у `<html>` — язык страницы: язык пользователя, если
школа его поддерживает, иначе основной язык школы.

## Переключатель «Школа видна в поисковых системах»

1. Откройте «Панель управления» → **«Вход и регистрация»** (страница «Приватность и регистрация»,
   `https://<домен-школы>/manage/school/privacy`).
2. Раскройте блок **«Расширенные настройки»** и включите или выключите **«Школа видна в поисковых системах»**
   (в корпоративной школе — «Компания видна в поисковых системах»).
3. Сохраните изменения.

<Info>
  Переключатель включён по умолчанию у всех школ — и у публичных, и у приватных: найти школу в поиске не значит в
  неё войти. Пока переключатель выключен, блок «Расширенные настройки» открывается сам. Менять настройку может
  менеджер с правом **«Управление настройками школы»** (`SchoolManageSettings`).
</Info>

Когда сайт школы закрыт от индексации:

- каждая страница сайта отдаётся с заголовком `X-Robots-Tag: noindex, nofollow` — поисковики уберут сайт из выдачи;
- `sitemap.xml` отвечает `404`, а в `robots.txt` нет строки `Sitemap`.

Так же сайт закрыт, если школа неактивна или у неё нет активной подписки — независимо от переключателя.

## sitemap.xml

Карта сайта собирается на лету по адресу `https://<домен-школы>/sitemap.xml` (кэшируется на час). Её отдаёт
только индексируемая школа и только на **каноническом домене**: если у школы подключён свой домен, карта есть
только на нём, а базовый адрес `*.exode.biz` отвечает `404` — так в карте не оказываются адреса чужого хоста.

| Школа | Что попадает в карту |
|-------|----------------------|
| Публичная | Главная (`/`), каталог (`/catalog`), курсы, показанные в каталоге (`/courses/1/<id>`, с `lastmod` по дате изменения курса), страница входа `/login/signin` и страницы сайта школы |
| Приватная | Только страница входа `/login/signin` — гостю приватная школа открывает только вход |

Страницы сайта школы в карте — [кастомные страницы](/ru/customization/custom-pages) с типом окна «Страница»,
открытые без входа (в форме страницы выключено «Требовать авторизацию»), кроме назначенной главной (она уже есть
как `/`). Окна («Плавающее окно», «Панель
справа», «Во весь экран»), системные страницы и страницы панели управления в карту не попадают.

## robots.txt

`robots.txt` один на все хосты платформы и собирается по домену запроса:

```txt robots.txt индексируемой школы
Sitemap: https://my-school.exode.biz/sitemap.xml

User-agent: *
Allow: /
Disallow: /invite/
```

Строку `Sitemap` получает только индексируемая школа на каноническом домене. Неиндексируемым хостам обход не
запрещается: под `Disallow` поисковик не открыл бы страницу и не увидел бы `noindex`, поэтому из выдачи их убирает
заголовок `X-Robots-Tag`. Если при сборке файла произошёл сбой, `robots.txt` всё равно отвечает `200` — без строки
`Sitemap`.

## Коды ответа

Сервер сайта школы отвечает честными кодами, чтобы поисковики не индексировали заглушки:

| Код | Когда |
|-----|-------|
| `404` | Школы с таким доменом нет; нет маршрута; нет курса, курс не опубликован или нет кастомной страницы с таким адресом. Страница «не найдено» рисуется на том же адресе, без редиректа |
| `410` | Школа в архиве: отдаётся страница с контактами поддержки школы |
| `503` | Временный сбой сервера или API; с заголовком `Retry-After: 120` — поисковик зайдёт позже |
