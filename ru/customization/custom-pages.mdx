Школа может создавать собственные страницы: каждая страница получает свой адрес
(`https://ваша-школа.exode.biz/ваш-slug`) и встраивает **мини-приложение** — сайт или
веб-приложение, размещённые где угодно (Vercel, свой сервер и т.д.), в iframe.

Мини-приложение получает от платформы подписанные данные пользователя ([Init Data](/ru/exode-sdk/miniapp/init-data)),
может проверить их на своём бэкенде и построить любую логику — от лендинга до полноценного
сервиса со своей базой данных.

## Создание страницы

1. Откройте «Панель управления» → «Школа» → «Кастомизация» → **«Приложения и страницы»**.
2. Нажмите «Создать приложение» и заполните:
   - **Название** — отображается в заголовке и меню (на языках школы);
   - **Адрес приложения (slug)** — строчные латинские буквы, цифры и дефис, 2–64 символа.
     Страница откроется по адресу `/<slug>`. Системные адреса платформы заняты;
   - **URL приложения (iframe)** — https-адрес вашего мини-приложения (он откроется в iframe);
   - **Тип окна** — как приложение показывается пользователю (см. ниже);
   - **Отображение** — только для типа «Страница»: «Во всю ширину» или «Остров» (карточка с отступами);
   - **Доступна без входа** — показывать ли страницу неавторизованным посетителям. Такой посетитель тоже
     получает подписанную Init Data, но без данных пользователя (`user` = `null`).
3. После создания откройте меню страницы «⋯» → **«Показать секрет»** — этот секрет нужен вашему
   серверу для [проверки Init Data](/ru/exode-sdk/miniapp/init-data). Храните его только на сервере.
   Там же — **«Перевыпустить секрет»**: старый секрет сразу перестаёт работать.

<Info>
  Создавать и редактировать страницы может менеджер с правом **«Управление приложениями и страницами»** (`SchoolManagePages`).
</Info>

<Note>
  Сайт мини-приложения должен разрешать встраивание в iframe: не отдавайте заголовок `X-Frame-Options`, а если
  используете `Content-Security-Policy: frame-ancestors`, укажите в нём домен школы.
</Note>

<Tip>
  Пункт меню для новой страницы добавьте в «Настройки» → «Левое меню сайта» со ссылкой `/<slug>` —
  переход будет внутренним, без перезагрузки. Открыть приложение можно и кнопкой
  из содержимого урока.
</Tip>

## Тип окна

| Тип | Как выглядит | Когда подходит |
|-----|--------------|----------------|
| **Страница** | Обычная страница платформы по адресу `/<slug>` | Лендинг, справочник, полноценный раздел |
| **Плавающее окно** | Окно поверх интерфейса, сворачивается в стопку | Чат, калькулятор, помощник — то, чем пользуются, не прерывая учёбу |
| **Панель справа** | Боковая панель рядом с содержимым | Заметки, подсказки, инструменты рядом с уроком |
| **Во весь экран** | Окно на весь экран поверх интерфейса, сворачивается в стопку, как остальные окна | Мастера и редакторы, которым нужно всё пространство, — например, конструктор курсов |

Развёрнутым может быть не более одного окна одновременно: при открытии второго первое
сворачивается. Свёрнутые окна копятся в «открывашке» и разворачиваются одним кликом.

На телефоне любой тип окна открывается как обычная страница.

## Параметры страницы

Параметры адреса страницы передаются в iframe query-строкой: ссылка `/<slug>?courseId=5` откроет приложение
по адресу `https://<ваше-приложение>/…?courseId=5#exodeInitData=…`. Если в URL приложения уже есть свой query,
параметры дописываются к нему, а Init Data по-прежнему приходит в hash. Служебные параметры платформы (`modal`,
`popup`, `appId`) в iframe не передаются.

Так работают все типы окна. Если приложение уже открыто, а его открывают с другими параметрами (например, чтобы
продолжить работу с другим курсом), iframe перезагружается с новым адресом; с теми же параметрами окно просто
разворачивается.

<Warning>
  Параметры приходят из адреса, который может подставить кто угодно. Используйте их только как подсказку, что
  открыть, а права на эту сущность проверяйте на своём сервере или запросом к API от имени пользователя.
</Warning>

<Note>
  Окно, восстановленное после перезагрузки платформы, открывается без параметров.
</Note>

## Главная страница школы

В списке страниц можно назначить **главную**: выбранная страница (системная или кастомная)
будет открываться на `/`. Кастомную страницу, назначенную главной, нельзя удалить или
выключить — сначала назначьте другую главную.

## Жизненный цикл iframe

Открытая страница-приложение не выгружается при навигации по платформе: iframe загружается
один раз и живёт в памяти, повторное открытие мгновенно. То же и со свёрнутым окном —
сворачивание не перезагружает приложение, состояние сохраняется.

Из самого мини-приложения доступны две команды ([MiniApp SDK](/ru/exode-sdk/miniapp/client)):

- `app.ui.minimize()` — свернуть окно (для типа «Страница» ничего не делает: сворачивать нечего);
- `app.ui.close()` — закрыть приложение и выгрузить iframe.

<Note>
  Платформа держит в памяти ограниченное число приложений и выгружает самые давние из
  неактивных. Не полагайтесь на то, что состояние переживёт закрытие — важные данные
  сохраняйте на своём сервере.
</Note>

Если приложение, которое по этому адресу уже делало handshake, в этот раз не ответило за 15 секунд, вместо него
показывается кнопка «Перезагрузить». Загрузить приложение заново можно и пунктом «Обновить» меню «…» в шапке
страницы — там же действия самого приложения (см. [Нативный вид](/ru/exode-sdk/miniapp/native)).

## Силуэт загрузки

Пока загружаются код и данные мини-приложения, платформа рисует на месте фрейма **силуэт загрузки** — блоки,
повторяющие первый экран приложения: без пустого экрана, спиннера и скачка, когда силуэт сменяется содержимым.
Силуэт задаётся в форме страницы, в поле **«Силуэт загрузки»** — одной строкой до 1024 символов, рядом с полем —
предпросмотр на экране телефона. Пустое поле — индикатор загрузки. Поле есть и у страниц установленных
мини-приложений.

```txt Пример
p12,16 g16; c48 208x28 g12; 226 r16; 96x22; 180*2; #2 120*2
```

- Ряды разделяются `;`, блоки ряда — пробелами.
- Первый ряд — только настройки страницы: `p12,16` — отступы (по вертикали, по горизонтали), `g16` — промежуток
  между рядами.
- Блоки: `226` — во всю ширину высотой 226 px; `208x28` — ширина × высота (ширина в px или долей ряда — `50%x20`);
  `c48` — круг; блок без ширины в ряду с другими занимает остаток. `~` — пружина: что дальше, уходит к правому краю
  (`c40 140x20 ~ 64x28` — аватар и заголовок, кнопка справа); `_16` — пустой отступ 16 px.
- Модификаторы ряда: `r16` — скругление блоков, `g12` — промежуток между ними, `m0,24` — поля ряда (по вертикали,
  по горизонтали), `al` / `ac` / `ar` / `as` — блоки к началу, по центру, к концу, врозь, `vt` / `vc` / `vb` — по
  верху, середине, низу ряда, `#2` — блок ряда два раза рядом (сетка), `*3` — ряд три раза (можно и в конце
  последнего блока: `180*2`).

Строку, которая не разбирается, форма не сохранит. Собирать её руками не обязательно: devtools SDK измеряют первый
экран приложения и выдают готовую строку — см. [Силуэт загрузки и devtools](/ru/exode-sdk/miniapp/native#силуэт-загрузки-и-devtools).
