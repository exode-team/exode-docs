```
GET /saas/v2/course/:courseId/get
```

Требуется аутентификация и одно из прав: [**«Управление курсами»**](/ru/exode-api/permissions) (`CourseManage`) или
**«Куратор курсов»** (`CourseCurator`). Метод доступен только школам.

Метод возвращает полный объект курса — в отличие от [Списка курсов](/ru/exode-api/school/course/list), который отдаёт
компактную проекцию. Модули, уроки и блоки в ответ не входят.

<Warning>
    **Режим доступа «Назначенные» действует и для API.** Право `CourseManage` даёт доступ к курсу, только если
    `settings.editorAccessMode` = `All`, право `CourseCurator` — только если `settings.curatorAccessMode` = `All`. К курсу
    в режиме `Assigned` у ключа есть доступ, только если его пользователь назначен на курс редактором или куратором.
    Иначе вернётся `Forbidden` с сообщением
    `Forbidden seller resource - product <ID продукта> permissions CourseManage CourseCurator`.
</Warning>

</ResponseField>

<RequestExample>
```bash cURL
curl --location 'https://api.exode.biz/saas/v2/course/412/get' \
  --header 'Seller-Id: {{ sellerId }}' \
  --header 'School-Id: {{ schoolId }}' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

```javascript Node.js
const axios = require('axios');

const getCourse = async (courseId) => {
  const { data } = await axios.get(`https://api.exode.biz/saas/v2/course/${courseId}/get`, {
    headers: {
      'Seller-Id': '{{ sellerId }}',
      'School-Id': '{{ schoolId }}',
      'Authorization': 'Bearer YOUR_TOKEN',
    },
  });

  console.log(data.payload);
};

getCourse(412);
```

```php PHP
<?php

$url = 'https://api.exode.biz/saas/v2/course/412/get';
$headers = [
  'Seller-Id: {{ sellerId }}',
  'School-Id: {{ schoolId }}',
  'Authorization: Bearer YOUR_TOKEN'
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

echo curl_exec($ch);
curl_close($ch);
?>
```
