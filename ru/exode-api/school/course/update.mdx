```
PUT /saas/v2/course/:courseId/update
```

Требуется аутентификация и право [**«Управление курсами»**](/ru/exode-api/permissions) (`CourseManage`). Метод доступен
только школам.

Метод меняет поля самого курса — те же, что при [создании](/ru/exode-api/school/course/create). Модули, уроки и блоки
этим методом не меняются: поле `modules` в теле игнорируется.

<Warning>
    **Режим доступа «Назначенные» действует и для API.** Если у курса `settings.editorAccessMode` = `Assigned`, изменить
    его может только ключ, пользователь которого назначен на курс (или владелец школы). Иначе вернётся `Forbidden`
    с сообщением `Forbidden seller resource - product <ID продукта> permissions CourseManage`. Курсы, созданные
    через [`course/create`](/ru/exode-api/school/course/create), доступны создавшему их ключу.
</Warning>

## Параметры пути

<ParamField path="courseId" type="integer" required>
    ID курса.
</ParamField>

## Параметры запроса

##### Все поля необязательны — передавайте только те, что меняете

<ParamField body="name" type="string" required={false}>
    Название курса. От 1 до 130 символов.
</ParamField>

<ParamField body="description" type="string" required={false}>
    Описание курса. До 500 символов.
</ParamField>

<ParamField body="type" type="enum" required={false}>
    Тип курса: `TextCourse`, `VideoCourse`, `Webinar`, `Assessment`, `PersonalLesson`, `Bundle`.
</ParamField>

<ParamField body="tags" type="string[]" required={false}>
    Теги курса (каждый — от 2 символов). Заменяют текущий список.
</ParamField>

<ParamField body="authors" type="integer[]" required={false}>
    ID пользователей-авторов. **Заменяют** текущий список авторов целиком — передавайте полный список, включая тех,
    кого нужно оставить.
</ParamField>

<ParamField body="subjectCategoryIds" type="integer[]" required={false}>
    ID предметных категорий. Заменяют текущий список.
</ParamField>

<ParamField body="contentCategoryId" type="integer" required={false}>
    ID контентной категории.
</ParamField>

<ParamField body="alias" type="string" required={false}>
    Символьный адрес курса: латинские буквы, цифры и `_`, уникальный.
</ParamField>

<ParamField body="image" type="object" required={false}>
    Изображения курса: `main`, `card` (URL).
</ParamField>

<ParamField body="promoVideo" type="string" required={false}>
    Ссылка на промо-видео.
</ParamField>

<ParamField body="seoTags" type="string[]" required={false}>
    SEO-теги.
</ParamField>

<ParamField body="settings" type="object" required={false}>
    Настройки курса — поля те же, что при [создании](/ru/exode-api/school/course/create#курс). Переданные поля
    сливаются с текущими настройками: непереданные остаются как были. Поля `certificate` тоже сливаются с текущими.
</ParamField>

<ParamField body="bundleCourses" type="object[]" required={false}>
    Только для курсов `Bundle` — состав пакета (формат — как при создании).
</ParamField>

<ParamField body="archivedAt" type="string" required={false}>
    Дата архивации (ISO 8601) — переводит курс в архив.
</ParamField>

<Note>
    Параметры продукта (`product`) этим методом не меняются — не передавайте поле `product`. Цена, валюта и
    показ в каталоге настраиваются в кабинете. Служебные поля `buildStatus` и `aiContext` тоже не передавайте.
</Note>

## Поля ответа

<ResponseField name="payload" type="object">

## Ошибки

| HTTP | `cause` | Когда возникает |
|---|---|---|
| 400 | `validation` | Тело не прошло проверку (тип, длина, enum) |
| 400 | `InvalidAlias` / `AliasAlreadyBusy` | Недопустимый или занятый `alias` |
| 400 | `CertificateTemplateRequired` / `CertificateTemplateNotAvailable` | Сертификат включён без шаблона или шаблон недоступен школе |
| 400 | `BundleGroupAlreadyUsed` / `BundleCourseSellerMismatch` | Ошибка в составе пакета `bundleCourses` |
| 401 | `Forbidden` | Курс не найден или принадлежит другой школе (`seller not entity owner`); у ключа нет права `CourseManage`; курс в режиме «Назначенные», а ключ на него не назначен (`product <ID> permissions CourseManage`) |
