<Info>
    Запись на курс выполняется через добавление пользователя в группу, привязанную к этому курсу.
    При добавлении участника в группу автоматически создаются связанные записи участников и доступов,
    и пользователь получает доступ к курсу.
</Info>

<Card title="Добавление участников в группу" icon="user-plus" href="/ru/exode-api/school/group-member/create-many">
    Эндпоинт записи пользователей в группу курса — `POST /saas/v2/group/:groupId/member/create-many`.
</Card>

## Как записать пользователя на курс

<Steps>
    <Step title="Найдите группу курса">
        Получите список групп с фильтром по курсу — эндпоинт
        [Список групп](/ru/exode-api/school/group/list) с параметром `courseIds`.
        В ответе у каждой группы указаны `courseId` и `courseName`, по которым можно убедиться,
        что группа относится к нужному курсу. ID групп курса также возвращает
        [Список курсов](/ru/exode-api/school/course/list) в поле `groupIds`.

        Если у курса несколько групп (например, потоки), выберите нужную по названию `name` — от группы
        зависят расписание, куратор и чаты участника.
    </Step>

    <Step title="Добавьте пользователей в группу">
        Запишите пользователей в найденную группу — эндпоинт
        [Добавление участников](/ru/exode-api/school/group-member/create-many):

        ```
        POST /saas/v2/group/:groupId/member/create-many
        ```

        В теле запроса передаётся массив `userIds` (числовые ID пользователей в Exode) — до 250 пользователей
        за один запрос. Если пользователь уже состоит в группе, повторно он добавлен не будет, поэтому запрос
        можно безопасно повторить. Если пользователя ещё нет в школе, сначала создайте его через
        [`user/create`](/ru/exode-api/school/user/create) или [`user/upsert`](/ru/exode-api/school/user/upsert).
    </Step>
</Steps>

<Check>
    После добавления в группу пользователь получает доступ к курсу, к которому привязана группа, а на ваш
    эндпоинт приходит вебхук `ProductEnrolledViaLms` (если на него есть подписка, см.
    [Вебхуки](/ru/exode-api/webhooks/about)).
</Check>
