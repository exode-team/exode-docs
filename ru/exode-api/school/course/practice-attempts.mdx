<HeaderParamFields/>

```
GET /saas/v2/course/:courseId/practice-attempts
```

<CourseAccessModeNote/>

<Info>
    Возвращает попытки прохождения практик выбранного курса: набранные и максимальные баллы, статус
    проверки, дедлайны и куратора. Одна запись — одна попытка одного ученика по одной практике.
</Info>

<Tip>
    Если нужна выгрузка большого объёма попыток файлом, используйте
    [выгрузку попыток практик](/ru/exode-api/school/query-export/practice-attempt-find-many).
    Этот метод предназначен для синхронного получения данных постранично.
</Tip>

## Параметры пути

<ParamField path="courseId" type="integer" required>
    ID курса, попытки по которому нужно получить.
</ParamField>

## Параметры запроса

<Note>
    Параметры-массивы передаются повторением параметра в строке запроса: `userIds=1&userIds=2`.
    Одиночное значение также допустимо.
</Note>

### Фильтры

<ParamField query="userIds" type="integer[]" required={false}>
    Ограничить выборку попытками конкретных учеников.
</ParamField>

<ParamField query="lessonIds" type="integer[]" required={false}>
    Ограничить выборку попытками по конкретным урокам.
</ParamField>

<ParamField query="practiceIds" type="integer[]" required={false}>
    Ограничить выборку попытками по конкретным практикам.
</ParamField>

<ParamField query="curatorIds" type="integer[]" required={false}>
    Попытки, проверенные конкретными кураторами.
</ParamField>

<ParamField query="statuses" type="enum[]" required={false}>
    Статусы попыток: `Created`, `OnReview`, `OnCorrection`, `Verified`, `AutoVerified`, `Failed`, `Stacked`.
</ParamField>

<ParamField query="finished" type="boolean" required={false}>
    Только завершённые (`true`) или незавершённые (`false`) попытки.
</ParamField>

<ParamField query="search" type="string" required={false}>
    Поиск по ученику.
</ParamField>

### Пагинация

<ParamField query="skip" type="integer" required={false}>
    Количество записей, которые нужно пропустить. По умолчанию `0`.
</ParamField>

<ParamField query="page" type="integer" required={false}>
    Номер страницы (альтернатива `skip`). Начинается с `1`.
</ParamField>

<ParamField query="take" type="integer" required={false}>
    Количество записей на странице. От `1` до `1000`. По умолчанию `100`.
</ParamField>

## Поля ответа

<ResponseField name="payload" type="object">
    Постраничный список попыток. Полная структура попытки — `courseLessonPracticeAttempt` в справочнике
    [`course`](/ru/exode-api/objects/entities/course).

    <Expandable title="Свойства payload">
        <ResponseField name="items" type="object[]">
            Массив попыток.

            <Expandable title="Свойства элемента">
                <ResponseField name="id" type="integer">ID попытки.</ResponseField>
                <ResponseField name="uuid" type="string | null">UUID попытки.</ResponseField>
                <ResponseField name="userId" type="integer">ID ученика.</ResponseField>
                <ResponseField name="practiceId" type="integer">ID практики.</ResponseField>
                <ResponseField name="lessonId" type="integer">ID урока, которому принадлежит практика.</ResponseField>
                <ResponseField name="variantId" type="integer">ID выданного варианта.</ResponseField>
                <ResponseField name="curatorId" type="integer | null">ID куратора, проверившего работу.</ResponseField>
                <ResponseField name="status" type="enum | null">
                    Статус попытки: `Created` — начата, `OnReview` — на проверке куратором,
                    `OnCorrection` — отправлена на доработку, `Verified` — проверена куратором,
                    `AutoVerified` — проверена автоматически, `Failed` — не пройдена, `Stacked` — прервана.
                </ResponseField>
                <ResponseField name="order" type="integer">Порядковый номер попытки ученика по этой практике.</ResponseField>
                <ResponseField name="finished" type="boolean">Попытка завершена.</ResponseField>
                <ResponseField name="pointsAmount" type="integer">Набранные баллы.</ResponseField>
                <ResponseField name="maxPointsAmount" type="integer">Максимально возможные баллы этой попытки.</ResponseField>
                <ResponseField name="correctPercent" type="integer | null">Процент правильных ответов.</ResponseField>
                <ResponseField name="isPassed" type="boolean | null">Попытка зачтена.</ResponseField>
                <ResponseField name="solvedCount" type="integer">Количество отвеченных заданий.</ResponseField>
                <ResponseField name="sentToReviewAt" type="string | null">Дата отправки на проверку (ISO 8601).</ResponseField>
                <ResponseField name="sentAfterDeadline" type="boolean">Работа отправлена после дедлайна.</ResponseField>
                <ResponseField name="deadlineAt" type="string | null">Дедлайн попытки (ISO 8601).</ResponseField>
                <ResponseField name="passedAt" type="string | null">Дата зачёта (ISO 8601).</ResponseField>
                <ResponseField name="isExpired" type="boolean | null">Дедлайн попытки истёк.</ResponseField>
                <ResponseField name="uncounted" type="boolean">Попытка не учитывается в результатах.</ResponseField>
                <ResponseField name="statusHistoryLogs" type="object[] | null">
                    История изменения статуса: массив объектов `{ timestamp, status }`.
                </ResponseField>
                <ResponseField name="createdAt" type="string">Дата создания (ISO 8601).</ResponseField>
                <ResponseField name="updatedAt" type="string">Дата обновления (ISO 8601).</ResponseField>
            </Expandable>
        </ResponseField>

        <ResponseField name="page" type="integer">Текущая страница.</ResponseField>
        <ResponseField name="count" type="integer">Общее количество записей.</ResponseField>
        <ResponseField name="pages" type="integer">Общее количество страниц.</ResponseField>
        <ResponseField name="isFirst" type="boolean">Признак первой страницы.</ResponseField>
        <ResponseField name="isLast" type="boolean">Признак последней страницы.</ResponseField>
        <ResponseField name="next" type="object">Параметры следующей страницы (`skip`, `take`, `page`).</ResponseField>
        <ResponseField name="prev" type="object">Параметры предыдущей страницы (`skip`, `take`, `page`).</ResponseField>
    </Expandable>
</ResponseField>

## Требования к правам доступа

<Check>
    Требуется аутентификация по токену и одно из прав: куратор курса (`CourseCurator`) или управление
    пользователями школы (`SchoolManageUsers`). Куратору возвращаются попытки только тех групп,
    которые он курирует.
</Check>
