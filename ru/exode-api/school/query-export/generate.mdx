## Как это работает

Генерация отчета выполняется через асинхронный workflow. Процесс состоит из трех шагов:

<Steps>
    <Step title="Создание задачи на генерацию">
        Отправьте `POST` запрос на `/saas/v2/query-export/generate` с указанием типа отчета, переменных фильтрации и
        формата.
        В ответ (HTTP `201`) вы получите объект с полем `payload`, содержащим `uuid` — идентификатор для
        отслеживания результата. Сам файл на этом шаге еще не создан.
    </Step>

    <Step title="Получение результата">
        Отправляйте `GET` запрос
        на <br/>[`/saas/v2/workflow-execution/:executionUuid/result`](/ru/exode-api/school/query-export/result), <br/>подставив
        `uuid` из первого шага, с интервалом 2–5 секунд.
        Повторяйте запрос до тех пор, пока `status` не станет `Completed` (или `Failed`). Сразу после запуска
        `payload` может быть `null` — задача еще не начала выполняться, продолжайте опрос.
    </Step>

    <Step title="Скачивание файла">
        При `status: Completed` скачайте файл по ссылке `payload.result.fileUrl`. Скачивайте сразу: результат
        хранится ограниченное время (подробнее — на странице [получения результата](/ru/exode-api/school/query-export/result)).
    </Step>
</Steps>

<Note>
    Сразу, со статусом `400` и `cause: "validation"`, отклоняется только запрос с неизвестным `type`, `format`
    или с `variables`, которое не является объектом. Ошибки внутри `variables` (неизвестное поле фильтра, неверное значение enum, отсутствующий `filter`) и нехватка прав
    на данные не приводят к ошибке этого запроса: задача создается, а при опросе результата приходит
    `status: Failed`. Причина ошибки в ответе не передается — сверьте запрос со страницей типа отчета и
    [правами](#требования-к-правам-доступа) токена.
</Note>

## Создание запроса на выгрузку

```
POST /saas/v2/query-export/generate
```

<Info>
  Rate limit: **100 запросов в час** на сервисного пользователя (токен). При превышении возвращается HTTP `429` —
  подробнее в разделе [Rate-limit](/ru/exode-api/setup#rate-limit). Опрос результата в этот лимит не входит.
</Info>

<ParamField header="Ux-Language" type="string">
  Язык заголовков колонок и переводимых значений в файле: `ru`, `en`, `uz`, `qa`. Если заголовок не передан,
  колонки называются по-английски. Названия колонок на страницах типов отчетов приведены для `ru`.
</ParamField>

### Параметры запроса

<ParamField body="type" type="string" required>
  Тип отчета. Определяет, какие данные будут выгружены. Доступные значения:

  - `QUERY_EXPORT_TYPE_SCHOOL_USER_FIND_MANY` — [пользователи школы](/ru/exode-api/school/query-export/school-user-find-many)
  - `QUERY_EXPORT_TYPE_SCHOOL_STUDENT_FIND_MANY` — [студенты школы](/ru/exode-api/school/query-export/school-student-find-many)
  - `QUERY_EXPORT_TYPE_GROUP_MEMBER_FIND_MANY` — [участники группы](/ru/exode-api/school/query-export/group-member-find-many)
  - `QUERY_EXPORT_TYPE_COURSE_LESSON_PRACTICE_ATTEMPT_FIND_MANY` — [попытки практических заданий](/ru/exode-api/school/query-export/practice-attempt-find-many)
  - `QUERY_EXPORT_TYPE_INVOICE_MANAGE_FIND_MANY` — [счета](/ru/exode-api/school/query-export/invoice-manage-find-many)
  - `QUERY_EXPORT_TYPE_PRODUCT_BILLING_ACCESS_FIND_MANY` — [биллинг доступов к продуктам](/ru/exode-api/school/query-export/product-billing-access-find-many)
</ParamField>

<ParamField body="variables" type="object" required>
  Переменные для запроса: `filter` (обязателен для всех типов; чтобы выгрузить все записи, передайте `{}`) и
  `sort` (необязателен). Набор полей зависит от выбранного `type` и описан на странице типа отчета — ссылки
  в списке выше.

  Поля проверяются при генерации, а не при создании задачи: неизвестное поле или неверное значение приводит
  к `status: Failed` на шаге получения результата. Даты в диапазонах (`...DateRange`) передаются в формате
  ISO 8601, например `2025-01-01T00:00:00Z`.
</ParamField>

<ParamField body="format" type="string">
  Формат выходного файла. По умолчанию — `EXPORT_FORMAT_XLSX`.

  - `EXPORT_FORMAT_XLSX` — Excel (.xlsx). Единственный формат с дополнительными листами (например, **Course
    Progress** или **Billing Details** — см. страницу типа отчета).
  - `EXPORT_FORMAT_CSV` — CSV (.csv): только основной лист, разделитель — запятая, кодировка UTF-8 с BOM
    (открывается в Excel без проблем с кириллицей), первая строка — заголовки колонок.
  - `EXPORT_FORMAT_JSON` — JSON (.json): массив объектов, по одному на строку отчета. Ключи — технические
    имена колонок на английском (`userId`, `fullName`, …), они не зависят от `Ux-Language`.
</ParamField>

### Поля ответа

<ResponseField name="success" type="boolean">
  Результат выполнения запроса.
</ResponseField>

<ResponseField name="code" type="number">
  HTTP-код ответа (например, `201`).
</ResponseField>

<ResponseField name="payload" type="object">
  Объект задачи генерации.

  <Expandable title="Свойства payload">
    <ResponseField name="uuid" type="string">
      UUID задачи — используется для [получения результата](/ru/exode-api/school/query-export/result).
    </ResponseField>

    <ResponseField name="flow" type="string">
      Тип процесса. Для выгрузок — `QueryExport`.
    </ResponseField>

    <ResponseField name="status" type="string">
      Статус задачи: `Waiting`, `Processing`, `Failed`, `Canceled`, `Completed` — расшифровка на странице
      [получения результата](/ru/exode-api/school/query-export/result). При создании — `Processing`.
    </ResponseField>

    <ResponseField name="isCompleted" type="boolean">
      Флаг завершения задачи. При создании — `false`.
    </ResponseField>

    <ResponseField name="userId" type="number | null">
      ID инициатора задачи — сервисного пользователя, которому принадлежит токен.
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Дата создания задачи (ISO 8601).
    </ResponseField>

    <ResponseField name="updatedAt" type="string | null">
      Дата последнего обновления задачи (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>

## Требования к правам доступа

Сам запрос на генерацию требует только аутентификации по токену сервисного пользователя школы. Данные для файла
собираются от имени этого же пользователя, поэтому токену нужно право на выгружаемые данные — одно из
перечисленных для типа отчета:

| Тип отчета | Нужное право (любое из) |
|---|---|
| `QUERY_EXPORT_TYPE_SCHOOL_USER_FIND_MANY` | **«Управление пользователями школы»** (`SchoolManageUsers`) |
| `QUERY_EXPORT_TYPE_SCHOOL_STUDENT_FIND_MANY` | **«Управление пользователями школы»** (`SchoolManageUsers`), **«Управление студентами курса»** (`CourseStudentManage`) |
| `QUERY_EXPORT_TYPE_GROUP_MEMBER_FIND_MANY` | **«Управление пользователями школы»** (`SchoolManageUsers`), **«Управление курсами»** (`CourseManage`), **«Куратор курсов»** (`CourseCurator`) |
| `QUERY_EXPORT_TYPE_COURSE_LESSON_PRACTICE_ATTEMPT_FIND_MANY` | **«Управление курсами»** (`CourseManage`), **«Куратор курсов»** (`CourseCurator`) |
| `QUERY_EXPORT_TYPE_INVOICE_MANAGE_FIND_MANY` | **«Продажи школы»** (`SellerSales`) |
| `QUERY_EXPORT_TYPE_PRODUCT_BILLING_ACCESS_FIND_MANY` | **«Управление пользователями школы»** (`SchoolManageUsers`), **«Управление студентами курса»** (`CourseStudentManage`) |

<Warning>
  Если права нет, запрос на генерацию все равно вернет `201`, а выгрузка завершится со `status: Failed`.
  Где включить права — в [справочнике прав](/ru/exode-api/permissions).
</Warning>
