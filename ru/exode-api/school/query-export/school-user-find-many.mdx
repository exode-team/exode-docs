**type:** `QUERY_EXPORT_TYPE_SCHOOL_USER_FIND_MANY`

Выгружает список пользователей школы с данными профиля, контактами, статусами доступа и активностью.

Это тип отчёта для метода [`query-export/generate`](/ru/exode-api/school/query-export/generate): передайте его
в поле `type`, а описанные ниже поля — в `variables`.

<Info>
  Структура `variables` повторяет фильтр и сортировку поиска пользователей школы.
  Неизвестное поле или неверное значение не игнорируется: выгрузка завершится со
  `status: Failed`.
</Info>

---

### Переменные (`variables`)

<ParamField body="filter" type="object" required>
  Параметры фильтрации. Обязателен: чтобы выгрузить все записи без фильтрации, передайте пустой объект `{}`.

  <Expandable title="Свойства filter">
    <ParamField body="userIds" type="integer[]">
      Фильтр по ID пользователей.
    </ParamField>

    <ParamField body="extIds" type="string[]">
      Фильтр по внешним идентификаторам (`extId`). До 250 значений, каждый до 50 символов.
    </ParamField>

    <ParamField body="search" type="string">
      Поиск по тексту (имя, email, телефон, домен), до 50 символов.
    </ParamField>

    <ParamField body="activated" type="boolean">
      Фильтр по признаку подтверждённого входа.
    </ParamField>

    <ParamField body="archived" type="boolean">
      Включать архивных пользователей.
    </ParamField>

    <ParamField body="statuses" type="string[]">
      Фильтр по статусам учётной записи. Массив из значений: `Active`, `OnLeave`, `Banned`, `Blocked`,
      `Terminated`, `Deleted`. Полей `active`/`banned` в фильтре нет — используйте `statuses`
      (например, заблокированные — `["Banned", "Blocked"]`). Запрос с `active` или `banned` завершится
      со `status: Failed`.
    </ParamField>

    <ParamField body="createdAtDateRange" type="object">
      Диапазон дат регистрации. Свойства `from` и `to` — даты в формате ISO 8601.
    </ParamField>

    <ParamField body="lastOnlineAtDateRange" type="object">
      Диапазон дат последней активности. Свойства `from` и `to` — даты в формате ISO 8601.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="sort" type="object">
  Параметры сортировки. Значения: `ASC` (по возрастанию) или `DESC` (по убыванию).

  <Expandable title="Свойства sort">
    <ParamField body="id" type="string">Сортировка по ID. `ASC` | `DESC`.</ParamField>
    <ParamField body="createdAt" type="string">Сортировка по дате регистрации. `ASC` | `DESC`.</ParamField>
    <ParamField body="updatedAt" type="string">Сортировка по дате обновления. `ASC` | `DESC`.</ParamField>
    <ParamField body="lastOnlineAt" type="string">Сортировка по последней активности. `ASC` | `DESC`.</ParamField>
    <ParamField body="starsBalance" type="string">Сортировка по балансу звёзд. `ASC` | `DESC`.</ParamField>
    <ParamField body="productAccessesCount" type="string">Сортировка по числу доступов к продуктам. `ASC` | `DESC`.</ParamField>
  </Expandable>
</ParamField>

### Колонки отчёта

Лист **SchoolUsers**: ID пользователя, Имя, Фамилия, Способ входа, Номер телефона, Почта, Telegram, Кол-во курсов,
Дата регистрации, Тип регистрации, Кем создан, Дата рождения, Дата последнего входа. При `filter.archived: true`
добавляются «Дата удаления» и «Кто удалил».

Названия колонок приведены для заголовка `Ux-Language: ru`; без него колонки называются по-английски
(подробнее — в описании [`generate`](/ru/exode-api/school/query-export/generate)).

## Требования к правам доступа

<Check>
  Требуется аутентификация по токену и право [**«Управление пользователями школы»**](/ru/exode-api/permissions) (`SchoolManageUsers`). Без права
