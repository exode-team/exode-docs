<Info>
  Платформа отслеживает **целевые события** (регистрация, просмотр курса, покупка и т.д.) и автоматически
  отправляет их во все подключенные рекламные площадки: **Meta Pixel (Facebook)**, **Google Analytics (GA4)**,
  **Яндекс.Метрику** и **VK Ads**. Достаточно вставить сниппет площадки в **Custom Code (JS)**
  в настройках школы — дополнительный код не нужен.
</Info>

## Список целевых событий

Каждое событие также диспатчится как `CustomEvent` на `document` (данные — в `event.detail`),
поэтому его можно перехватить своим кодом для любой другой площадки.

| Событие | Когда срабатывает | `event.detail` |
| --- | --- | --- |
| `analytics:signup-completed` | Регистрация нового аккаунта через email или телефон | `{ method: 'email' \| 'phone' }` |
| `profile:personal-info-filled-success` | Пользователь заполнил анкету онбординга (имя и личные данные) | — |
| `analytics:course-viewed` | Просмотр страницы курса | `{ courseId: number }` |
| `analytics:demo-lesson-opened` | Открытие демо-урока со страницы курса | `{ courseId: number, lessonId: number }` |
| `analytics:free-course-enrolled` | Запись на бесплатный курс | `{ productId: number }` |
| `analytics:checkout-initiated` | Переход к оформлению оплаты (выбран тариф) | `{ productId: number, priceId: number }` |
| `analytics:purchase-completed` | Успешная оплата счета | `{ value: number, currency: string, productIds: number[] }` |
| `analytics:course-completed` | Пользователь завершил курс | `{ productId: number }` |

<Warning>
  События отправляются на стороне браузера. `analytics:signup-completed` срабатывает только при
  регистрации через email/телефон — вход через соцсети (VK, Telegram) и OTP пока не различает
  нового пользователя и повторный вход, поэтому событие для них не отправляется.
</Warning>

## Подключение площадок

Все площадки подключаются одинаково — вставьте стандартный сниппет в **Custom Code (JS)**:

<AccordionGroup>
  <Accordion title="Meta Pixel (Facebook)">
    Вставьте стандартный сниппет Meta Pixel с вашим Pixel ID. Платформа обнаружит `window.fbq`
    и начнет отправлять события автоматически.
  </Accordion>

  <Accordion title="Google Analytics (GA4)">
    Вставьте стандартный сниппет Google tag (gtag.js) с вашим Measurement ID. Платформа обнаружит
    `window.gtag` и начнет отправлять события автоматически.
  </Accordion>

  <Accordion title="Яндекс.Метрика">
    Вставьте стандартный сниппет счетчика и дополнительно укажите его номер в `window.YM_ID` —
    он нужен платформе для вызова `reachGoal`:

    ```html
    <script>
        // ... стандартный сниппет счетчика Яндекс.Метрики ...

        window.YM_ID = 12345678; // номер вашего счетчика
    </script>
    ```

    В настройках счетчика создайте JS-цели с идентификаторами из таблицы ниже.
  </Accordion>

  <Accordion title="VK Ads (top.mail.ru)">
    Вставьте стандартный сниппет пикселя VK Ads и дополнительно укажите его ID в `window.VK_PIXEL_ID`:

    ```html
    <script>
        // ... стандартный сниппет пикселя VK Ads ...

        window.VK_PIXEL_ID = 3456789; // ID вашего пикселя
    </script>
    ```

    В кабинете VK Ads создайте цели с идентификаторами из таблицы ниже.
  </Accordion>
</AccordionGroup>

## Маппинг событий по площадкам

| Событие платформы | Meta Pixel | GA4 (gtag) | Цель Метрики / VK Ads |
| --- | --- | --- | --- |
| `analytics:signup-completed` | `CompleteRegistration` | `sign_up` | `signup` |
| `profile:personal-info-filled-success` | `Lead` | `generate_lead` | `lead` |
| `analytics:course-viewed` | `ViewContent` | `view_item` | `view_course` |
| `analytics:demo-lesson-opened` | `ViewDemoLesson` (custom) | `view_demo_lesson` | `view_demo_lesson` |
| `analytics:free-course-enrolled` | `StartTrial` | `free_course_enroll` | `free_course_enroll` |
| `analytics:checkout-initiated` | `InitiateCheckout` | `begin_checkout` | `begin_checkout` |
| `analytics:purchase-completed` | `Purchase` | `purchase` | `purchase` |
| `analytics:course-completed` | `CompleteCourse` (custom) | `complete_course` | `complete_course` |

<Note>
  `CompleteRegistration`, `Lead`, `ViewContent`, `StartTrial`, `InitiateCheckout`, `Purchase` —
  [стандартные события Meta](https://www.facebook.com/business/help/402791146561655), по ним доступна
  автоматическая оптимизация рекламы; `ViewDemoLesson` и `CompleteCourse` отправляются через
  `fbq('trackCustom', ...)`. Для GA4 `sign_up`, `generate_lead`, `view_item`, `begin_checkout`
  и `purchase` — рекомендованные события Google.

  Событие покупки отправляется один раз на счет и передает сумму: `value` + `currency` (ISO 4217)
  в Meta и GA4, `order_price` в Метрику, `value` в VK Ads. При оплате внутренними валютами (баллы)
  Meta и GA4 событие не получают, в Метрику и VK Ads цель `purchase` уходит без суммы.
</Note>

## Другие площадки

Для площадки без встроенной поддержки подпишитесь на события платформы своим кодом
в **Custom Code (JS)** и вызовите JS API площадки:

```html
<script>
    document.addEventListener('analytics:purchase-completed', function (e) {
        // любой пиксель: e.detail.value, e.detail.currency, e.detail.productIds
    });

    document.addEventListener('analytics:signup-completed', function (e) {
        // e.detail.method: 'email' | 'phone'
    });
</script>
```

<Tip>
  Если для вашей площадки нужна встроенная поддержка — напишите нам в
  [поддержку](https://t.me/exode_support_biz), добавим на стороне платформы.
</Tip>
