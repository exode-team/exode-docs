<Info>
  Платформа отслеживает **целевые события** (регистрация, просмотр курса, покупка и т.д.) и автоматически
  отправляет их во все подключенные рекламные площадки. Достаточно вставить сниппет площадки
  в **Custom Code (JS)** в настройках школы — дополнительный код не нужен.
</Info>

## Целевые события

Каждое событие также диспатчится как `CustomEvent` на `document` (данные — в `event.detail`),
поэтому его можно перехватить своим кодом для любой другой площадки.

<ParamField body="analytics:signup-completed" type="event">
    Регистрация нового аккаунта через email или телефон. При входе через соцсети (VK, Telegram)
    и OTP событие не отправляется — этот способ пока не различает нового пользователя и повторный вход.

    <Expandable title="Поля event.detail">
        <ParamField body="method" type="enum">Способ регистрации: `email`, `phone`.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="profile:personal-info-filled-success" type="event">
    Пользователь заполнил анкету онбординга (имя и личные данные). Без `event.detail`.
</ParamField>

<ParamField body="analytics:course-viewed" type="event">
    Просмотр страницы курса.

    <Expandable title="Поля event.detail">
        <ParamField body="courseId" type="number">ID курса.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="analytics:demo-lesson-opened" type="event">
    Открытие демо-урока со страницы курса.

    <Expandable title="Поля event.detail">
        <ParamField body="courseId" type="number">ID курса.</ParamField>
        <ParamField body="lessonId" type="number">ID демо-урока.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="analytics:free-course-enrolled" type="event">
    Запись на бесплатный курс.

    <Expandable title="Поля event.detail">
        <ParamField body="productId" type="number">ID продукта курса.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="analytics:checkout-initiated" type="event">
    Переход к оформлению оплаты (выбран тариф).

    <Expandable title="Поля event.detail">
        <ParamField body="productId" type="number">ID продукта.</ParamField>
        <ParamField body="priceId" type="number">ID выбранного тарифа.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="analytics:purchase-completed" type="event">
    Успешная оплата счета. Отправляется **один раз на счет**: повторная отправка на этом устройстве
    блокируется на 90 дней по uuid счета, а при позднем открытии страницы (другое устройство,
    ссылка из письма — позже 5 минут после оплаты) событие не отправляется вовсе.

    <Expandable title="Поля event.detail">
        <ParamField body="value" type="number">Сумма счета.</ParamField>
        <ParamField body="currency" type="enum">Валюта счета: `Rub`, `Uzs`, `Kzt`, `Usd`, `Eur`, `Exes`, `Free`.</ParamField>
        <ParamField body="invoiceUuid" type="string">Uuid счета — уникальный идентификатор для дедупликации.</ParamField>
        <ParamField body="productIds" type="number[]">ID оплаченных продуктов.</ParamField>
    </Expandable>
</ParamField>

<ParamField body="analytics:course-completed" type="event">
    Пользователь завершил курс.

    <Expandable title="Поля event.detail">
        <ParamField body="productId" type="number">ID продукта курса.</ParamField>
    </Expandable>
</ParamField>

## Meta Pixel (Facebook)

Вставьте стандартный сниппет Meta Pixel с вашим Pixel ID в **Custom Code (JS)**.
Платформа обнаружит `window.fbq` и начнет отправлять события автоматически.

Отправляемые события — [стандартные события Meta](https://www.facebook.com/business/help/402791146561655)
(по ним доступна автоматическая оптимизация рекламы) и два кастомных:

<ParamField body="CompleteRegistration" type="track">
    Регистрация нового аккаунта. Параметр `registration_method` — `email` или `phone`.
</ParamField>

<ParamField body="Lead" type="track">
    Заполнена анкета онбординга.
</ParamField>

<ParamField body="ViewContent" type="track">
    Просмотр страницы курса. Параметры: `content_type: 'product'`, `content_ids`.
</ParamField>

<ParamField body="ViewDemoLesson" type="trackCustom">
    Открытие демо-урока. Параметры: `content_ids`, `lesson_id`. Кастомное событие —
    для него можно настроить custom conversion в Events Manager.
</ParamField>

<ParamField body="StartTrial" type="track">
    Запись на бесплатный курс. Параметр `content_ids`.
</ParamField>

<ParamField body="InitiateCheckout" type="track">
    Переход к оплате. Параметры: `num_items`, `content_ids`.
</ParamField>

<ParamField body="Purchase" type="track">
    Успешная оплата. Параметры: `value`, `currency` (ISO 4217), `content_type`, `content_ids`.
    Uuid счета передается как `eventID` — Meta сама схлопывает дубли с одинаковым `eventID`
    в течение 48 часов. При оплате внутренними валютами (баллы) событие не отправляется —
    Meta требует реальную валюту.
</ParamField>

<ParamField body="CompleteCourse" type="trackCustom">
    Завершение курса. Параметр `content_ids`. Кастомное событие.
</ParamField>

## Google Analytics (GA4)

Вставьте стандартный сниппет Google tag (gtag.js) с вашим Measurement ID в **Custom Code (JS)**.
Платформа обнаружит `window.gtag` и начнет отправлять события автоматически.

Где возможно, используются [рекомендованные события Google](https://support.google.com/analytics/answer/9267735),
остальные — кастомные:

<ParamField body="sign_up" type="event">
    Регистрация нового аккаунта. Параметр `method` — `email` или `phone`.
</ParamField>

<ParamField body="generate_lead" type="event">
    Заполнена анкета онбординга.
</ParamField>

<ParamField body="view_item" type="event">
    Просмотр страницы курса. Параметр `items` с `item_id` курса.
</ParamField>

<ParamField body="view_demo_lesson" type="event">
    Открытие демо-урока. Параметры: `item_id`, `lesson_id`. Кастомное событие.
</ParamField>

<ParamField body="free_course_enroll" type="event">
    Запись на бесплатный курс. Параметр `item_id`. Кастомное событие.
</ParamField>

<ParamField body="begin_checkout" type="event">
    Переход к оплате. Параметр `items` с `item_id` продукта.
</ParamField>

<ParamField body="purchase" type="event">
    Успешная оплата. Параметры: `value`, `currency` (ISO 4217), `items`, `transaction_id`
    (uuid счета — GA4 сама игнорирует повторные покупки с тем же `transaction_id`).
    При оплате внутренними валютами (баллы) событие не отправляется.
</ParamField>

<ParamField body="complete_course" type="event">
    Завершение курса. Параметр `item_id`. Кастомное событие.
</ParamField>

## Яндекс.Метрика

Вставьте стандартный сниппет счетчика в **Custom Code (JS)** и дополнительно укажите его номер
в `window.YM_ID` — он нужен платформе для вызова `reachGoal`:

```html
<script>
    // ... стандартный сниппет счетчика Яндекс.Метрики ...

    window.YM_ID = 12345678; // номер вашего счетчика
</script>
```

В настройках счетчика создайте [JS-цели](https://yandex.ru/support/metrica/general/goal-js-event.html)
с идентификаторами:

<ParamField body="signup" type="reachGoal">
    Регистрация нового аккаунта.
</ParamField>

<ParamField body="lead" type="reachGoal">
    Заполнена анкета онбординга.
</ParamField>

<ParamField body="view_course" type="reachGoal">
    Просмотр страницы курса.
</ParamField>

<ParamField body="view_demo_lesson" type="reachGoal">
    Открытие демо-урока.
</ParamField>

<ParamField body="free_course_enroll" type="reachGoal">
    Запись на бесплатный курс.
</ParamField>

<ParamField body="begin_checkout" type="reachGoal">
    Переход к оплате.
</ParamField>

<ParamField body="purchase" type="reachGoal">
    Успешная оплата. Параметры цели: `order_price`, `currency` (для внутренних валют не передаются).
</ParamField>

<ParamField body="complete_course" type="reachGoal">
    Завершение курса.
</ParamField>

## VK Ads (top.mail.ru)

Вставьте стандартный сниппет пикселя VK Ads в **Custom Code (JS)** и дополнительно укажите его ID
в `window.VK_PIXEL_ID`:

```html
<script>
    // ... стандартный сниппет пикселя VK Ads ...

    window.VK_PIXEL_ID = 3456789; // ID вашего пикселя
</script>
```

В кабинете VK Ads создайте цели с теми же идентификаторами, что и для Метрики:
`signup`, `lead`, `view_course`, `view_demo_lesson`, `free_course_enroll`, `begin_checkout`,
`purchase` (с передачей `value` — суммой оплаты), `complete_course`.

## Другие площадки

Для площадки без встроенной поддержки подпишитесь на [целевые события](#целевые-события)
своим кодом в **Custom Code (JS)** и вызовите JS API площадки:

```html
<script>
    document.addEventListener('analytics:purchase-completed', function (e) {
        // любой пиксель: e.detail.value, e.detail.currency, e.detail.productIds
    });

    document.addEventListener('analytics:signup-completed', function (e) {
        // e.detail.method: 'email' | 'phone'
    });
</script>
```

<Tip>
  Если для вашей площадки нужна встроенная поддержка — напишите нам в
  [поддержку](https://t.me/exode_support_biz), добавим на стороне платформы.
</Tip>
