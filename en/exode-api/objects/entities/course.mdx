This page covers the public structures of learning-related objects: `course`, `courseProgress`,
`courseLesson`, `courseLessonPractice`, `courseLessonPracticeAttempt`. They are returned by the course
methods and in webhooks (`CourseCompleted`, `CourseProgressChanged`, `CourseLessonPracticeCompleted`).

<Info>
    The [`course/list/raw`](/en/exode-api/school/course/list) method returns a compact projection
    (`courseId`, `productId`, `name`, `type`, `groupIds`). The full public entity schemas are below.
</Info>

## `course`

<ResponseField name="id" type="integer" required>Course ID.</ResponseField>
<ResponseField name="type" type="enum" required>Type: `Bundle`, `Webinar`, `TextCourse`, `Assessment`, `VideoCourse`, `PersonalLesson`.</ResponseField>
<ResponseField name="productId" type="integer | null">ID of the [product](/en/exode-api/objects/entities/product) through which the course is sold and access to it is granted.</ResponseField>
<ResponseField name="contentCategoryId" type="integer | null">Content category ID.</ResponseField>
<ResponseField name="buildStatus" type="enum" required>
    Course build state: `Ready` — the course is ready; `AiGenerating` — the course is still being generated by AI.
</ResponseField>
<ResponseField name="name" type="string" required>Name.</ResponseField>
<ResponseField name="description" type="string" required>Description.</ResponseField>
<ResponseField name="alias" type="string | null">Text alias.</ResponseField>
<ResponseField name="tags" type="string[]" required>Tags.</ResponseField>
<ResponseField name="seoTags" type="string[]" required>SEO tags.</ResponseField>
<ResponseField name="image" type="object | null">Images: `{ main, wrapper }`.</ResponseField>
<ResponseField name="promoVideo" type="string | null">Promo video.</ResponseField>
<ResponseField name="settings" type="object" required>Course settings (arbitrary object).</ResponseField>
<ResponseField name="order" type="integer" required>Sort order.</ResponseField>
<ResponseField name="isBundle" type="boolean | null">Whether the course is a bundle.</ResponseField>
<ResponseField name="createdAt" type="string" required>Creation date (ISO 8601).</ResponseField>
<ResponseField name="updatedAt" type="string" required>Update date (ISO 8601).</ResponseField>
<ResponseField name="archivedAt" type="string | null">Archiving date or `null`.</ResponseField>

## `courseProgress`

Returned by the [`course/:courseId/progresses`](/en/exode-api/school/course/progresses) method. A record describes
a user's progress in a specific lesson.

<ResponseField name="id" type="integer" required>Progress record ID.</ResponseField>
<ResponseField name="courseId" type="integer | null">Course ID.</ResponseField>
<ResponseField name="userId" type="integer" required>User ID.</ResponseField>
<ResponseField name="lessonId" type="integer" required>Lesson ID.</ResponseField>
<ResponseField name="status" type="enum | null">
    Lesson status. The completion stages that are stored in the progress record (they also arrive in the
    `CourseProgressChanged` webhook):

    - `NotStarted` — the student has access but has not opened the lesson yet;
    - `OnTheory` — the student is studying the theory;
    - `OnPractice` — the student has opened the practice part;
    - `OnReview` — the assignment has been sent to the curator and is awaiting review;
    - `OnCorrection` — the curator has returned the assignment for revision;
    - `Completed` — the lesson is fully completed.

    The other values describe lesson availability and are computed on the fly: `NotInitialized` (no progress
    record yet), `NotParticipant`, `AvailableAsDemo`, `ExpiredByGroup`, `DisabledByGroup`, `AllowedByProgress`,
    `BlockedByProgress`, `StartScheduled`, `StartScheduledWaitPrev`, `BundleStartBlocked`,
    `BundleStartPendingConfirmation`.
</ResponseField>
<ResponseField name="scheduleStartAt" type="string | null">Scheduled start (ISO 8601).</ResponseField>
<ResponseField name="scheduleFinishAt" type="string | null">Scheduled end (ISO 8601).</ResponseField>
<ResponseField name="practiceDeadlineAt" type="string | null">Practice deadline (ISO 8601).</ResponseField>
<ResponseField name="isCompleted" type="boolean | null">The lesson is completed.</ResponseField>
<ResponseField name="isOnReview" type="boolean | null">Under review.</ResponseField>
<ResponseField name="completedAt" type="string | null">Completion date (ISO 8601).</ResponseField>
<ResponseField name="onReviewAt" type="string | null">Date sent for review (ISO 8601).</ResponseField>
<ResponseField name="statusHistoryLogs" type="object[] | null">Status history: `{ timestamp, status }`.</ResponseField>
<ResponseField name="createdAt" type="string" required>Creation date (ISO 8601).</ResponseField>
<ResponseField name="updatedAt" type="string" required>Update date (ISO 8601).</ResponseField>
<ResponseField name="archivedAt" type="string | null">Archiving date or `null`.</ResponseField>
