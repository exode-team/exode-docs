### How to request a new API method

You can request a new API method, and we will implement it within 1 week after the requirements are agreed.

<Steps>
<Step title="Contact support in Telegram">
  Describe the task: the business goal, resource/entity, HTTP method and route, query/body parameters, expected response schema and examples.

  <Card title="Open support in Telegram" href="https://t.me/exode_support_biz">
  Contact our team: we will respond quickly and clarify the details.
  </Card>
</Step>

<Step title="Agreement and development (up to 7 days)">
  We will clarify the requirements, confirm the timeline and start development.

  <Check>
  The finished method, documentation and usage examples will be available within 1 week.
  </Check>
</Step>
</Steps>

<Tip>
To speed up development, attach example requests/responses and any business validation rules.
</Tip>
