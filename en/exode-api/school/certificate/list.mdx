<HeaderParamFields/>

```
GET /saas/v2/certificate/list/raw
```

<Info>
    Returns certificates issued for the school's courses. All filter parameters are optional — without them
    the method returns all of the school's certificates page by page, from newest to oldest (by descending `certificateId`).
    Array parameters are passed by repeating the parameter: `courseIds=1&courseIds=2`.
</Info>

## Request parameters

### Pagination

<ParamField query="skip" type="integer" required={false}>
    Number of records to skip. Defaults to `0`.
</ParamField>

<ParamField query="page" type="integer" required={false}>
    Page number (an alternative to `skip`). Starts at `1`.
</ParamField>

<ParamField query="take" type="integer" required={false}>
    Number of records per page. From `1` to `1000`. Defaults to `100`.
</ParamField>

### Filtering

<ParamField query="certificateIds" type="integer[]" required={false}>
    Filter by certificate IDs.
</ParamField>

<ParamField query="courseIds" type="integer[]" required={false}>
    Filter by IDs of the courses the certificate was issued for.
</ParamField>

<ParamField query="userIds" type="integer[]" required={false}>
    Filter by recipient user IDs.
</ParamField>

<ParamField query="groupIds" type="integer[]" required={false}>
    Filter by group IDs. A group is linked to the recipient, not to the certificate: the results include
    certificates of users who are members of at least one of the specified groups.
</ParamField>

<ParamField query="issuedAtDateRange" type="object" required={false}>
    Issue date range.

    <Expandable title="issuedAtDateRange properties">
        <ParamField query="from" type="string">Start of the range (ISO 8601), exclusive.</ParamField>
        <ParamField query="to" type="string">End of the range (ISO 8601), inclusive.</ParamField>
    </Expandable>
</ParamField>

<ParamField query="archived" type="boolean" required={false}>
    Filter by the certificate's archived state: `true` — archived only, `false` — non-archived only. If omitted,
    both are returned.
</ParamField>

## Response fields

<ResponseField name="payload" type="object">
    Paginated list of certificates (compact projection). The full structure is in the
    [`certificate`](/en/exode-api/objects/entities/certificate) reference.

    <Expandable title="payload properties">
        <ResponseField name="items" type="object[]">
            Array of certificates.

            <Expandable title="Item properties">
                <ResponseField name="certificateId" type="integer">Certificate ID.</ResponseField>
                <ResponseField name="uuid" type="string">Public identifier of the certificate.</ResponseField>
                <ResponseField name="link" type="string">
                    Public link to the certificate. It opens without authorization, and you can also print it to PDF from there.
                </ResponseField>
                <ResponseField name="courseId" type="integer">Course ID.</ResponseField>
                <ResponseField name="courseName" type="string | null">Course name.</ResponseField>
                <ResponseField name="issuedAt" type="string">Issue date (ISO 8601).</ResponseField>
                <ResponseField name="expireAt" type="string | null">
                    Expiration date (ISO 8601), or `null` if the certificate does not expire.
                </ResponseField>
                <ResponseField name="user" type="object | null">
                    The recipient with their profile — a [`user`](/en/exode-api/objects/entities/user) object.
                    Users deleted via [`user/delete-many`](/en/exode-api/school/user/delete-many)
                    are returned with `status: "Deleted"`; `null` if the user record is unavailable.
                </ResponseField>
            </Expandable>
        </ResponseField>

        <ResponseField name="page" type="integer">Current page.</ResponseField>
        <ResponseField name="count" type="integer">Total number of records.</ResponseField>
        <ResponseField name="pages" type="integer">Total number of pages.</ResponseField>
        <ResponseField name="isFirst" type="boolean">Whether this is the first page.</ResponseField>
        <ResponseField name="isLast" type="boolean">Whether this is the last page.</ResponseField>
        <ResponseField name="next" type="object">Parameters of the next page (`skip`, `take`, `page`).</ResponseField>
        <ResponseField name="prev" type="object">Parameters of the previous page (`skip`, `take`, `page`).</ResponseField>
    </Expandable>
</ResponseField>
