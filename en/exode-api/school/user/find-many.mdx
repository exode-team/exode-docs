<HeaderParamFields/>

```
POST /saas/v2/user/find-many
```

Requires authentication and the [**"School User Management"**](/en/exode-api/permissions) permission (`SchoolManageUsers`).

<Tip>
    To find a single user, use
    [Find by identifier](/en/exode-api/school/user/find).
</Tip>

## Request parameters

##### Pass at least one of the identifier lists

<Info>
  The method returns an array of found users. Users that could not be found are not included in the response —
  match the result to the request by `email`/`phone`/`domain`/`tgId`/`extId` on your side. If several lists are
  passed, the conditions are combined with "OR": the response includes every user matching at least one
  value from any list — each user at most once. The order of items in the response does not
  match the order in the request.
</Info>

<ParamField body="logins" type="string[]" required={false}>
  A list of user logins: email, phone in international format, or domain login (`domain`, for example
  `i_ivanov`; a value like `id12345` finds the user with ID `12345`). From 2 to 50 characters each, up to
  250 items.
</ParamField>

<ParamField body="tgIds" type="integer[]" required={false}>
  A list of users' Telegram IDs. Up to 250 items.
</ParamField>

<ParamField body="extIds" type="string[]" required={false}>
  A list of external identifiers from your system. From 1 to 50 characters each, up to 250 items.
</ParamField>

<Warning>
  You must pass **at least one non-empty** list. Each list is limited to 250 items.
</Warning>

<RequestExample>
```bash cURL
curl --location 'https://api.exode.biz/saas/v2/user/find-many' \
  --header 'Seller-Id: {{ sellerId }}' \
  --header 'School-Id: {{ schoolId }}' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer YOUR_TOKEN' \
  --data-raw '{
    "logins": ["user@example.com", "+9876543210"]
  }'
```

```javascript Node.js
const axios = require('axios');

const findManyUsers = async () => {
  try {
    const response = await axios.post('https://api.exode.biz/saas/v2/user/find-many', {
      logins: ['user@example.com', '+9876543210']
    }, {
      headers: {
        'Seller-Id': '{{ sellerId }}',
        'School-Id': '{{ schoolId }}',
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_TOKEN'
      }
    });

    console.log('Users found:', response.data.payload.users);
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
};

findManyUsers();
```

```python Python
import requests
import json

url = 'https://api.exode.biz/saas/v2/user/find-many'

data = {
  'logins': ['user@example.com', '+9876543210']
}

headers = {
  'Seller-Id': '{{ sellerId }}',
  'School-Id': '{{ schoolId }}',
  'Content-Type': 'application/json',
  'Authorization': 'Bearer YOUR_TOKEN'
}

response = requests.post(url, json=data, headers=headers)
response.raise_for_status()

result = response.json()
print(json.dumps(result['payload']['users'], indent=2, ensure_ascii=False))
```
