**type:** `QUERY_EXPORT_TYPE_COURSE_LESSON_PRACTICE_ATTEMPT_FIND_MANY`

This is a report type for the [`query-export/generate`](/en/exode-api/school/query-export/generate) method: pass it
in the `type` field, and the fields described below in `variables`.

Exports a list of practice assignment attempts with grades, statuses and student information.

### Report columns

Column names are shown as returned without the `Ux-Language: ru` header (in English); with that header, columns are named in Russian
(see [`generate`](/en/exode-api/school/query-export/generate) for details). Sheet: **PracticeAttempts**.

- User ID
- Full name
- Login method
- Phone number
- Course ID
- Course name
- Curator/Reviewer
- Lesson
- Status
- Correct answers count
- Total questions
- Scored points
- Total points
- Scored points %
- Attempt #
- Max attempts
- Sent to review
- Deadline
- After deadline
- Created at
- Last activity

<Info>
    An export in **JSON** format additionally includes technical fields: `email`, `attemptId`, `practiceId`,
    `studentSex`, `dateOfBirth`, `addedDate`, `lessonId`, `totalTasks`, `maxPointsAmount`, `pointsAmount`,
    `statusHistoryLogs`, `attemptUpdatedAt`.
</Info>

## Permission requirements

<Check>
  Requires token authentication and one of the permissions: [**"Course Management"**](/en/exode-api/permissions) (`CourseManage`) or
  **"Course Curator"** (`CourseCurator`). Without the permission, the generation request succeeds, but the export ends with
  `status: Failed`.
