**type:** `QUERY_EXPORT_TYPE_INVOICE_MANAGE_FIND_MANY`

Exports the list of the school's invoices with amounts, types, payment statuses and related payments.

This is a report type for the [`query-export/generate`](/en/exode-api/school/query-export/generate) method: pass it
in the `type` field, and pass the fields described below in `variables`.

<Info>
  The set of filters matches the [Invoice list](/en/exode-api/school/invoice/list) method, which also describes
  the nested `payment` and `utmParams` filters. An unknown field or an invalid value is not ignored: the export
  finishes with `status: Failed`.
</Info>

---

### Variables (`variables`)

<ParamField body="filter" type="object" required>
  Filter parameters. Required: to export all records without filtering, pass an empty object `{}`.

  <Expandable title="filter properties">
    <ParamField body="invoiceIds" type="integer[]">
      Filter by invoice IDs.
    </ParamField>

    <ParamField body="userIds" type="integer[]">
      Filter by user (payer) IDs.
    </ParamField>

    <ParamField body="productIds" type="integer[]">
      Filter by product IDs.
    </ParamField>

    <ParamField body="types" type="string[]">
      Filter by invoice types. An array of values: `Regular`, `InstallmentInit`, `InstallmentPay`,
      `SubscriptionInit`, `SubscriptionPay`.
    </ParamField>

    <ParamField body="search" type="string">
      Text search, up to 50 characters.
    </ParamField>

    <ParamField body="totalAmountRange" type="object">
      Invoice amount range. The `from` and `to` properties are numbers.
    </ParamField>

    <ParamField body="createdAtDateRange" type="object">
      Range of invoice creation dates. The `from` and `to` properties are dates in ISO 8601 format.
    </ParamField>

    <ParamField body="payment" type="object">
      Nested filter by the related payment (status, provider, etc.).
    </ParamField>

    <ParamField body="utmParams" type="object">
      Filter by the invoice's UTM tags. The `value` field is an array of `{ key, value }` pairs (non-empty strings).
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="sort" type="object">
  Sorting parameters. Values: `ASC` (ascending) or `DESC` (descending).

  <Expandable title="sort properties">
    <ParamField body="id" type="string">Sort by ID. `ASC` | `DESC`.</ParamField>
    <ParamField body="createdAt" type="string">Sort by creation date. `ASC` | `DESC`.</ParamField>
    <ParamField body="updatedAt" type="string">Sort by update date. `ASC` | `DESC`.</ParamField>
    <ParamField body="status" type="string">Sort by invoice status. `ASC` | `DESC`.</ParamField>
    <ParamField body="totalAmount" type="string">Sort by amount. `ASC` | `DESC`.</ParamField>
    <ParamField body="paidAtOrCreatedAt" type="string">Sort by payment date (or creation date). `ASC` | `DESC`.</ParamField>
    <ParamField body="userLastOnlineAt" type="string">Sort by the payer's last activity. `ASC` | `DESC`.</ParamField>
    <ParamField body="paymentActualStatus" type="string">Sort by the actual payment status. `ASC` | `DESC`.</ParamField>
  </Expandable>
</ParamField>

### Report columns

**Invoices** sheet: User ID, Full name, Login method, Phone number, Email, Telegram, Payment ID, Payment
date, Course ID, Course name, Tariff ID, Tariff, Payment type, Payment method, Status, Total amount,
Currency.

Column names are given as they appear without the `Ux-Language` header (in English); with the header, they are translated
into the specified language (see the [`generate`](/en/exode-api/school/query-export/generate) description for details).

## Permission requirements

<Check>
  Requires token authentication and the [**"School Sales"**](/en/exode-api/permissions) permission (`SellerSales`). Without the permission, the generation request
  succeeds, but the export finishes with `status: Failed`.
</Check>
