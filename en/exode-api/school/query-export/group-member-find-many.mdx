**type:** `QUERY_EXPORT_TYPE_GROUP_MEMBER_FIND_MANY`

Exports a list of group members with information about course progress, curator, tariff and activity.

This is a report type for the [`query-export/generate`](/en/exode-api/school/query-export/generate) method: pass it
in the `type` field, and the fields described below in `variables`.

### Report columns

Column names are given as they appear without the `Ux-Language` header (English by default); the header switches
them to another language, e.g. `Ux-Language: ru` (see [`generate`](/en/exode-api/school/query-export/generate) for details).

Main sheet **GroupMembers**:

- User ID
- Full name
- Login method
- Phone number
- Course ID
- Course name
- Access status
- Group
- Curator
- Current lesson
- Progress (%)
- Completed lessons
- Total lessons
- Date added
- Tariff ID
- Tariff
- Invited by
- Completion date
- Last activity

In XLSX format only, if the export contains bundles, a **Course Progress** sheet is generated — a breakdown of progress
by the bundle's nested courses:

- User ID
- Full name
- Bundle ID
- Bundle name
- Course ID
- Course name
- Progress (%)
- Completed lessons
- Total lessons
- Current lesson

<ParamField body="filter" type="object" required>
  Filtering parameters. Required: to export all records without filtering, pass an empty object `{}`.

  <Expandable title="filter properties">
    <ParamField body="memberIds" type="integer[]">
      Filter by group member IDs.
    </ParamField>

    <ParamField body="groupIds" type="integer[]">
      Filter by group IDs.
    </ParamField>

    <ParamField body="productIds" type="integer[]">
      Filter by product IDs.
    </ParamField>

    <ParamField body="userIds" type="integer[]">
      Filter by user IDs.
    </ParamField>

    <ParamField body="currentLessonIds" type="integer[]">
      Filter by IDs of members' current lessons.
    </ParamField>

    <ParamField body="participantCuratorIds" type="integer[]">
      Filter by curator IDs (seller manager IDs).
    </ParamField>

    <ParamField body="inviterUserIds" type="integer[]">
      Filter by IDs of users who added the member.
    </ParamField>

    <ParamField body="active" type="boolean">
      Filter by access status. `true` — active only, `false` — deactivated only.
    </ParamField>

    <ParamField body="participantStatuses" type="string[]">
      Filter by product participant statuses. An array of values: `InUse`, `Completed`.
    </ParamField>

    <ParamField body="search" type="string">
      Text search (up to 50 characters).
    </ParamField>

    <ParamField body="progressPercentRange" type="object">
      Filter by progress range (in percent). The `from` and `to` properties are numbers.
    </ParamField>

    <ParamField body="createdAtDateRange" type="object">
      Filter by access creation date range. The `from` and `to` properties are dates in ISO 8601 format.
    </ParamField>

    <ParamField body="product" type="object">
      Nested product filter. The set of fields matches the `product` filter of the
      ["List product accesses"](/en/exode-api/school/product-access/list) method.
    </ParamField>

    <ParamField body="price" type="object">
      Nested filter by the product's tariff (price). The set of fields matches the `price` filter of the
      ["List product accesses"](/en/exode-api/school/product-access/list) method.
    </ParamField>
  </Expandable>
</ParamField>

  </Expandable>

## Permission requirements

<Check>
  Requires token authentication and one of the permissions: [**"School User Management"**](/en/exode-api/permissions) (`SchoolManageUsers`),
  **"Course Management"** (`CourseManage`) or **"Course Curator"** (`CourseCurator`). Without the permission, the generation
  request succeeds, but the export ends with `status: Failed`.
</Check>
