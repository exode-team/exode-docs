title: "School students"
description: "Export school students (course accesses) with progress, groups, curators and tariffs"

**type:** `QUERY_EXPORT_TYPE_SCHOOL_STUDENT_FIND_MANY`

Exports the school's students through their course accesses: course progress, groups, curator, tariff and access status
(one student = one product access).

This is a report type for the [`query-export/generate`](/en/exode-api/school/query-export/generate) method: pass it
in the `type` field, and pass the filter and sorting in `variables`.

<Info>
  Students are exported from product accesses (`productAccessManageFindMany`): one student = one course access.
  That is why `variables` is the access filter and sorting (`FilterAccessProductInput` / `SortAccessProductInput`),
  the same structure as in the
  ["Access billing"](/en/exode-api/school/query-export/product-billing-access-find-many) report.
  An unknown field or an invalid value is not ignored: the export finishes with
  `status: Failed`.
</Info>

### Variables (`variables`)

<ParamField body="filter" type="object" required>
  Access filter parameters. Required: to export all records without filtering, pass an empty
  object `{}`.

  <Expandable title="filter properties">
    <ParamField body="userIds" type="integer[]">Filter by user IDs.</ParamField>
    <ParamField body="accessIds" type="integer[]">Filter by access IDs.</ParamField>
    <ParamField body="courseIds" type="integer[]">Filter by course IDs.</ParamField>
    <ParamField body="groupIds" type="integer[]">Filter by IDs of the groups the student belongs to.</ParamField>
    <ParamField body="launchIds" type="integer[]">Filter by launch (cohort) IDs.</ParamField>
    <ParamField body="active" type="boolean">Only active (`true`) or deactivated (`false`) accesses.</ParamField>
    <ParamField body="search" type="string">Text search (name, email, phone, domain), up to 50 characters.</ParamField>
    <ParamField body="currentLessonIds" type="integer[]">Filter by IDs of the students' current lessons.</ParamField>
    <ParamField body="participantCuratorIds" type="integer[]">Filter by curator IDs (seller manager IDs).</ParamField>
    <ParamField body="enrolledByUserIds" type="integer[]">Filter by IDs of the users who granted the access.</ParamField>
    <ParamField body="participantStatuses" type="string[]">
      Product participant status. An array of values: `InUse`, `Completed`.
    </ParamField>
    <ParamField body="progressPercentRange" type="object">
      Progress range (in percent). The `from` and `to` properties are numbers.
    </ParamField>
    <ParamField body="createdAtDateRange" type="object">
      Range of access grant dates. The `from` and `to` properties are ISO 8601 dates.
    </ParamField>
    <ParamField body="expireAtDateRange" type="object">
      Range of access expiration dates. The `from` and `to` properties are ISO 8601 dates.
    </ParamField>
    <ParamField body="product" type="object">
      Nested product filter (for example, `{ "productIds": [12] }`). The set of fields matches the `product`
      filter of the ["Product access list"](/en/exode-api/school/product-access/list) method. If a
      non-empty `product.productIds` is set, the "Last activity" and "Access status" columns are added to the report.
    </ParamField>
    <ParamField body="price" type="object">
      Nested tariff filter. The set of fields matches the `price` filter of the
      ["Product access list"](/en/exode-api/school/product-access/list) method.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="sort" type="object">
  Sorting parameters. Values: `ASC` (ascending) or `DESC` (descending).

  <Expandable title="sort properties">
    <ParamField body="id" type="string">Sort by ID. `ASC` | `DESC`.</ParamField>
    <ParamField body="createdAt" type="string">Sort by access grant date. `ASC` | `DESC`.</ParamField>
    <ParamField body="updatedAt" type="string">Sort by update date. `ASC` | `DESC`.</ParamField>
    <ParamField body="expireAt" type="string">Sort by access expiration date. `ASC` | `DESC`.</ParamField>
    <ParamField body="progressPercent" type="string">Sort by progress (%). `ASC` | `DESC`.</ParamField>
    <ParamField body="userLastOnlineAt" type="string">Sort by the student's last activity. `ASC` | `DESC`.</ParamField>
  </Expandable>
</ParamField>

### Report columns

**SchoolStudents** sheet: User ID, Full name, Login method, Course ID, Course name, Group ID, Group,
Curator, Current lesson, Progress (%), Completed lessons, Total lessons, Date added, Access expiration
date, Tariff ID, Tariff. With a non-empty `filter.product.productIds`, "Last activity" and "Access
status" are added. Corporate schools do not have the "Tariff ID" and "Tariff" columns.

In XLSX format only, if the export contains bundles, a **Course Progress** sheet is generated with a breakdown of progress
by the bundle's nested courses: User ID, Full name, Bundle ID, Bundle name, Course ID, Course name,
Progress (%), Completed lessons, Total lessons, Current lesson.

Column names are given as they appear without the `Ux-Language` header (in English); with the header, they are translated
into the specified language (see the [`generate`](/en/exode-api/school/query-export/generate) description for details).

## Permission requirements

<Check>
  Requires token authentication and one of the permissions: [**"School User Management"**](/en/exode-api/permissions) (`SchoolManageUsers`)
  or **"Course Student Management"** (`CourseStudentManage`). Without the permission, the generation request succeeds, but
  the export finishes with `status: Failed`.
</Check>
