<HeaderParamFields/>

```
PUT /saas/v2/form/layout/:layoutId/update
```

Requires authentication and the [**"Forms management"**](/en/exode-api/permissions) permission (`FormManage`).

## Path parameters

<ParamField path="layoutId" type="integer" required={true}>
  ID of the form layout to update. The layout must belong to the current school.
</ParamField>

## Request parameters

<Info>
  All request body parameters are optional. Pass only the fields you want to update.
</Info>

<ParamField body="mode" type="enum" required={false}>
  Form layout mode. Possible values: `Custom`, `Form`, `Signup`, `Welcome`, `Participant`.
</ParamField>

<ParamField body="name" type="string" required={false}>
  Form layout name. Maximum 255 characters.
</ParamField>

<ParamField body="internalName" type="string" required={false}>
  Internal layout name. Maximum 255 characters.
</ParamField>

<ParamField body="status" type="enum" required={false}>
  Layout status. Possible values: `Draft`, `Published`.
</ParamField>

<ParamField body="slug" type="string" required={false}>
  Layout slug. From 1 to 50 characters. Must be unique within the seller (school).
</ParamField>

<ParamField body="note" type="string" required={false}>
  Layout note. Maximum 255 characters.
</ParamField>

<ParamField body="productIds" type="integer[]" required={false}>
  Array of IDs of the products the layout is linked to. When passed, it fully replaces the current list of linked products.
</ParamField>

<ParamField body="config" type="object" required={false}>
  Layout settings.

  <Expandable title="config properties">
    <ParamField body="resubmitMode" type="enum" required={false}>
      Form resubmission mode. Possible values: `Overwrite`, `NewFill`, `NotAllowed`.
    </ParamField>
  </Expandable>
</ParamField>

```javascript Node.js
const axios = require('axios');

const updateLayout = async () => {
  const layoutId = 5;

  try {
    const response = await axios.put(`https://api.exode.biz/saas/v2/form/layout/${layoutId}/update`, {
      name: 'Updated name',
      status: 'Published',
      config: {
        resubmitMode: 'NotAllowed'
      }
    }, {
      headers: {
        'Seller-Id': '{{ sellerId }}',
        'School-Id': '{{ schoolId }}',
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_TOKEN'
      }
    });

    console.log('Layout updated:', response.data.payload);
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
};

updateLayout();
```

## Permission requirements

<Check>
  Updating a form layout requires the service user to have the **"Forms management"** permission (`FormManage`).
</Check>

<Check>
  The layout must belong to the current school (checked automatically).
</Check>

<Warning>
  The service user must be authenticated with a token and have the appropriate access permissions for the specified
  school.
</Warning>
