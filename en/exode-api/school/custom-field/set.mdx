<HeaderParamFields/>

```
POST /saas/v2/form/custom-field/value/set
POST /saas/v2/form/custom-field/value/set-by-slug
```

Requires authentication and the [**"Forms management"**](/en/exode-api/permissions) permission (`FormManage`).

## Request parameters

Two formats are available for passing values: **by slug** (recommended) and **by fieldId** (advanced).

<ParamField body="userId" type="integer" required={true}>
  Numeric ID of the Exode user (the `id` field from [`user/find`](/en/exode-api/school/user/find)) for whom
  the field values are set. The user must belong to the school from the `School-Id` header.
</ParamField>

<ParamField body="layoutId" type="integer" required={true}>
  ID of the form layout the fields belong to — the `id` field from the [form list](/en/exode-api/school/form-layout/list).
  All fields from `values` must belong to this layout (otherwise — `FieldNotBelongsToLayout`).
</ParamField>

<Tip>
  **Where to get `slug` and `fieldId`.** Form fields are created in the school's admin panel (not through the API); the
  field's code (`slug`) is set there as well. `fieldId`, `slug` and the field type are also returned by
  [getting values](/en/exode-api/school/custom-field/get) in the nested `field` object.
  **Which method to choose:** `set-by-slug` is more convenient — the slug is stable and the value type is matched to the field
  automatically; use `set` if you already store `fieldId` on your side.
</Tip>

### Format 1: By slug (recommended)

**Endpoint:** `POST /saas/v2/form/custom-field/value/set-by-slug`

Simplified format — the value type is determined automatically based on the field type in the layout.

<ParamField body="values" type="object[]" required={true}>
  Array of field values. At least 1 element.

  <Expandable title="values element properties">
    <ParamField body="slug" type="string" required={true}>
      The field code.
    </ParamField>

    <ParamField body="value" type="any" required={false}>
      The field value. The type must match the field type:

      | Field type | Expected `value` type | Example |
      |---|---|---|
      | Text, Textarea, Select, Radio | `string` | `"Tashkent"` |
      | Number | `number` | `25` |
      | Boolean, Switch, Checkbox | `boolean` | `true` |
      | Date | `string` (ISO 8601) | `"2025-03-10T12:00:00.000Z"` |
      | Json, File, Multiselect | `object` | `{"key": "value"}` |

      Pass `null` to clear the value.
    </ParamField>
  </Expandable>
</ParamField>

### Format 2: By fieldId (advanced)

**Endpoint:** `POST /saas/v2/form/custom-field/value/set`

Typed format — you specify the column for the value yourself.

<ParamField body="values" type="object[]" required={true}>
  Array of field values. At least 1 element.

  <Expandable title="values element properties">
    <ParamField body="fieldId" type="integer" required={true}>
      ID of the field for which the value is set.
    </ParamField>

    <ParamField body="text" type="string" required={false}>
      Text value. For fields: Text, Select, Radio, Textarea.
    </ParamField>

    <ParamField body="number" type="number" required={false}>
      Numeric value. For fields: Number.
    </ParamField>

    <ParamField body="boolean" type="boolean" required={false}>
      Boolean value. For fields: Boolean, Switch, Checkbox.
    </ParamField>

    <ParamField body="date" type="string" required={false}>
      Date in ISO 8601 format. For fields: Date.
    </ParamField>

    <ParamField body="json" type="object" required={false}>
      JSON object. For fields: Json, File, Multiselect.
    </ParamField>
  </Expandable>
</ParamField>

<Info>
  Both methods work in **upsert** mode — if a field value already exists for this user, it is
  updated. If it doesn't exist, it is created. One value is stored per "user + field" pair, so
  a repeated call is safe and simply overwrites the value. Fields not passed in `values` are not changed.
  If at least one field from the request is not found or not writable, the entire request is rejected.
</Info>

<Warning>
  Fields whose RBAC settings have `api = false` (API access denied) cannot be written
  through this method — the `FieldWritePermissionDenied` error is returned. The permission is changed in the field settings in the admin panel.
</Warning>

```javascript Node.js (by slug)
const axios = require('axios');

const setFieldValues = async () => {
  try {
    const response = await axios.post('https://api.exode.biz/saas/v2/form/custom-field/value/set-by-slug', {
      userId: 27,
      layoutId: 5,
      values: [
        { slug: 'city', value: 'Tashkent' },
        { slug: 'age', value: 25 },
        { slug: 'is-active', value: true }
      ]
    }, {
      headers: {
        'Seller-Id': '{{ sellerId }}',
        'School-Id': '{{ schoolId }}',
        'Content-Type': 'application/json',
        'Authorization': 'Bearer YOUR_TOKEN'
      }
    });

    console.log('Values set:', response.data.payload);
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
};

setFieldValues();
```

```php PHP (by slug)
<?php

$url = 'https://api.exode.biz/saas/v2/form/custom-field/value/set-by-slug';
$data = [
  'userId' => 27,
  'layoutId' => 5,
  'values' => [
    [ 'slug' => 'city', 'value' => 'Tashkent' ],
    [ 'slug' => 'age', 'value' => 25 ],
    [ 'slug' => 'is-active', 'value' => true ]
  ]
];

$headers = [
  'Seller-Id: {{ sellerId }}',
  'School-Id: {{ schoolId }}',
  'Content-Type: application/json',
  'Authorization: Bearer YOUR_TOKEN'
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

if ($httpCode === 201) {
  $result = json_decode($response, true);
  echo "Values set successfully\n";
  print_r($result['payload']);
} else {
  echo "Error: HTTP $httpCode\n";
  echo $response;
}
?>
```

```python Python (by slug)
import requests
import json

  'userId': 27,
  'layoutId': 5,

    { 'slug': 'city', 'value': 'Tashkent' },

headers = {
  'Seller-Id': '{{ sellerId }}',
  'School-Id': '{{ schoolId }}',
  'Content-Type': 'application/json',
  'Authorization': 'Bearer YOUR_TOKEN'
}

try:
  response = requests.post(url, json=data, headers=headers)
  response.raise_for_status()

  result = response.json()
  print('Values set successfully:')
  print(json.dumps(result['payload'], indent=2, ensure_ascii=False))

except requests.exceptions.RequestException as e:

  if hasattr(e, 'response') and e.response is not None:
    print(f'Response: {e.response.text}')
```

## Permission requirements

<Check>
  Setting custom field values requires the service user to have the **"Forms management"** permission (`FormManage`).
</Check>

<Warning>
  The service user must be authenticated with a token and have the appropriate access permissions for the specified
  school.
</Warning>

<Info>
  The form layout (`layoutId`) must belong to the current school. The user (`userId`) must be a member of this school.
</Info>
