```
GET /saas/v2/course/:courseId/get
```

Requires authentication and one of the permissions: [**"Course Management"**](/en/exode-api/permissions)
(`CourseManage`) or **"Course Curator"** (`CourseCurator`). The method is available to schools only.

The method returns the full course object — unlike the [Course list](/en/exode-api/school/course/list), which returns a
compact projection. Modules, lessons and blocks are not included in the response.

<Warning>
    **The "Assigned" access mode applies to the API too.** The `CourseManage` permission grants access to the course only
    if `settings.editorAccessMode` = `All`, and `CourseCurator` only if `settings.curatorAccessMode` = `All`. For a course
    in the `Assigned` mode the key has access only if its user is assigned to the course as an editor or a curator.
    Otherwise `Forbidden` is returned with the message
    `Forbidden seller resource - product <product ID> permissions CourseManage CourseCurator`.
</Warning>

</ParamField>

## Response fields

</ResponseField>

  --header 'Authorization: Bearer YOUR_TOKEN'

```javascript Node.js
const axios = require('axios');

const getCourse = async (courseId) => {
  const { data } = await axios.get(`https://api.exode.biz/saas/v2/course/${courseId}/get`, {
    headers: {
      'Seller-Id': '{{ sellerId }}',
      'School-Id': '{{ schoolId }}',
      'Authorization': 'Bearer YOUR_TOKEN',
    },
  });

  console.log(data.payload);
};

getCourse(412);
```
