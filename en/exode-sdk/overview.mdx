`@exode-team/sdk` is the official Exode npm package that combines two independent modules: a server-side client for the School API and a bridge for embedded mini apps (MiniApp) — a client part for the iframe and a server part for verifying signatures.

<CardGroup cols={2}>
  <Card title="API Client" icon="plug" href="/en/exode-sdk/api-client">
    A typed client for the `/saas/v2/*` REST endpoints. Used on the server (Node.js) and covers
    users, employees (HR), groups, courses, certificates, accesses, invoices, forms and exports.
  </Card>

  <Card title="MiniApp Bridge" icon="window-restore" href="/en/exode-sdk/miniapp/introduction">
    Client SDK for iframe apps: handshake with the host, navigation, UI commands, events, React hooks.
  </Card>
</CardGroup>

## Package modules

| Import | Purpose | Environment |
|--------|-----------|-------|
| `@exode-team/sdk/api` | Server-side SaaS API client | Node.js ≥18 |
| `@exode-team/sdk/miniapp` | Bridge for iframe mini apps | Browser |
| `@exode-team/sdk/miniapp/react` | React hooks on top of the bridge | Browser + React ≥17 |
| `@exode-team/sdk/miniapp/server` | Signature verification for [Init Data](/en/exode-sdk/miniapp/init-data) and webhooks (`verifyInitData`, `verifyWebhookSignature`) | Node.js ≥18 |

<Info>
  The package is split into independent subpath exports. Import only the module you need — tree-shaking removes the rest from the bundle.
</Info>
