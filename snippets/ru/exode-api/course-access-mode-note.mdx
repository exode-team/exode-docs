<Warning>
    **Ограничение видимости курса на API не распространяется.** У курса есть режимы доступа
    для команды школы («Все» / «Назначенные»), которые скрывают закрытый курс от менеджеров
    в интерфейсе. API отдаёт данные по всем курсам школы независимо от этих режимов —
    доступ определяется только токеном сервисного пользователя и его правами.
</Warning>
